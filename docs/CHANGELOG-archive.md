## 📌 이전 업데이트 (2026-06-30) — Step 1/2 UX 일괄 개선 + 미매칭 매칭 편의화

> 11개 개선 항목(A~E) + 라이브/제외 상태 + 미매칭 매칭을 SDD로 적용. 전부 **표시/UX 전용 — 점수·집계·파이프라인 불변**. 상세는 `docs/superpowers/specs/2026-06-30-*`·`2026-06-29-batch*`.

- **소재 상태 배지 (라이브/중단/제외)** — 표 소재명 앞 색 점. 자동 판정(최근 노출) + 상세 모달 수동 지정(localStorage 개인). 표시 전용 (`step1_integrated.html` `resolveStatus`/`statusBadgeHtml`).
- **소재 목록 표 강화** — 컬럼 헤더 클릭 정렬 · 체크박스 선택 소재만 집계(통계는 전체 고정) · Google Ads/MMP 지표 명칭 통일 · 툴팁 깨짐 수정.
- **상세 모달 일별 추이 차트** — 전환/노출/CPA 토글 (Chart.js, `renderModalTrend`).
- **성과별 강·약점 태그** — 전체 성과 요약에 종합점수 상위 공통 강점 / 하위 공통 약점 Top5 (`buildPerfTagAnalysis`).
- **미매칭 매칭 편의화** — 미매칭 패널 기본 접기 + "매핑 반영 파일 생성"이 현재 `titles_overrides.json` fetch→딥 병합→**완전 파일** 출력(복사·다운로드, 기존 설정 보존) (`buildAliasConfig`/`downloadAliasConfig`).

### ✨ TXT 소재 분석 완전 제외 — 전 페이지 통일 적용

#### 변경 배경
TXT 소재(광고 제목/설명 텍스트)는 파일명·태그 정보가 없어 크리에이티브 분석에 적합하지 않습니다.  
기존에는 `step1_integrated.html`에서 TXT 체크박스가 UI에 노출되어 사용자가 실수로 선택할 수 있었고,  
`step2_clustering.html`에서는 TXT를 포함한 전체 rows를 군집화에 사용하는 문제가 있었습니다.

#### 수정 내용

| 파일 | 변경 내용 |
|------|----------|
| `step1_integrated.html` | • 소재 유형 필터에서 TXT 체크박스 완전 제거 (BNR/VID만 표시)<br>• `updateTypeFilter()` / `updateFatigueTypeFilter()` 에서 TXT 참조 제거 |
| `step2_clustering.html` | • `runClustering()` 내 `aggregateByMaterial()` 호출 전 BNR/VID 필터링 추가<br>• 로딩 메시지에 `TXT N개 제외` 문구 표시<br>• 설정 요약 카드 소재 수: `BNR/VID N개 (TXT N개 제외)` 형태로 변경<br>• 헤더 메타 배지도 BNR/VID 수 기준으로 변경 |
| `step2_column_selector.html` | • 업로드 토스트/메타 텍스트에 `TXT N개 자동 제외` 안내 추가 |

#### 적용 방식
```
// 모든 TXT 필터링에 동일한 패턴 사용
const bnrVidRows = csvData.rows.filter(row => {
  const t = (row['유형'] || row['앱 확장 소재 유형'] || '').toUpperCase().trim();
  return t === 'BNR' || t === 'VID';
});
```

- **기준 기간 (Baseline Period)**: 비교의 기준이 되는 시점 설정
- **비교 기간 (Comparison Period)**: 성과 변화를 확인할 시점 설정
- **자동 날짜 범위 설정**: CSV 업로드 시 전반부/후반부로 기본값 자동 설정

  - ▲ 상승 (녹색)
  - ▼ 하락 (빨강)

  - 🆕 신규 소재 (파랑)
- **테이블 정렬**: 기준 기간 순위 오름차순 (1위부터 순서대로)

#### 4. 피로도 상태 판정 로직 (CPA 기준)
**중요**: CPA(Cost Per Action) 변화율을 기준으로 피로도를 판정합니다.

4단계 자동 분류 시스템:
- **🟢 신선 (Fresh)**: CPA 20% 이상 하락 → **성과 크게 개선** → Scale-up 권장
- **🔵 안정 (Stable)**: CPA 0~10% 범위 → **안정적 성과** → 현 상태 유지
- **🟡 주의 (Warning)**: CPA 0~20% 상승 → **경미한 악화** → 모니터링 강화
- **🔴 피로 (Tired)**: CPA 20% 이상 상승 → **성과 크게 악화** → 교체 또는 리프레시 필요

**판정 로직**:
```javascript
// CPA 변화율 = ((비교 기간 CPA - 기준 기간 CPA) / 기준 기간 CPA) × 100
// 음수 = CPA 하락 (좋음), 양수 = CPA 상승 (나쁨)

if (cpaChangeRate <= -20) → 신선 (Fresh)
else if (cpaChangeRate > -20 && cpaChangeRate <= 0) → 안정 (Stable)
else if (cpaChangeRate > 0 && cpaChangeRate < 20) → 주의 (Warning)
else → 피로 (Tired)
```

- 일부 브라우저/환경에서 `youtube.com` 임베드가 차단됨

**해결 방법**:
- ✅ **`youtube-nocookie.com` 사용**: 개인정보 보호 강화 도메인으로 변경
- ✅ **추가 파라미터**: `rel=0` (관련 동영상 최소화), `modestbranding=1` (YouTube 로고 최소화)
- ✅ **권한 확대**: `web-share` 추가
- ✅ **Referrer Policy**: `strict-origin-when-cross-origin` 설정

**변경 전**:
```javascript
iframe.src = `https://www.youtube.com/embed/${videoId}?autoplay=1`;
```

**변경 후**:
```javascript
iframe.src = `https://www.youtube-nocookie.com/embed/${videoId}?autoplay=1&rel=0&modestbranding=1`;
iframe.allow = 'accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share';
iframe.setAttribute('referrerpolicy', 'strict-origin-when-cross-origin');
```

**효과**:
- ✅ 오류 153 해결 (임베드 제한 우회)
- ✅ 사용자 프라이버시 강화 (쿠키 없음)
- ✅ 크로스 브라우저 호환성 개선
- ✅ 안정적인 동영상 재생

### ✨ Step 1: 동영상 미리보기 개선 완료 (이전 업데이트)

**배경**: VID(동영상) 타입 소재는 YouTube 링크만 있고 썸네일 이미지가 없어 미리보기가 표시되지 않던 문제

**개선 내용**:

1. **동영상 전용 플레이 버튼 썸네일**
   - VID 타입 자동 감지 시 보라색 그라데이션 배경에 ▶ 플레이 아이콘 표시
   - 우측 하단에 'VID' 배지 추가로 유형 명확화
   - 호버 시 보라색 글로우 효과 (box-shadow)
   - CSS 그라데이션: `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`

2. **모달에서 YouTube 임베드 재생**
   - 동영상 클릭 시 YouTube 임베드 iframe 자동 생성
   - `autoplay=1` 파라미터로 즉시 재생
   - 모달 크기: 최대 70vh, 반응형
   - 허용 권한: accelerometer, autoplay, encrypted-media, gyroscope, picture-in-picture
   - YouTube URL 자동 파싱: `extractYouTubeID()` 함수

3. **유형별 차별화된 UX**
   - **BNR (이미지)**: 실제 이미지 썸네일 → 클릭 시 고해상도 이미지 모달
   - **VID (동영상)**: 플레이 버튼 썸네일 → 클릭 시 YouTube 임베드 재생
   - 상세 정보에 유형 명시: "VID (동영상)" / "BNR (이미지)"
   - 링크 텍스트 동적 변경: "YouTube에서 보기" / "원본 이미지 보기"

4. **성능 최적화**
   - 모달 닫을 때 iframe 자동 제거 (메모리 누수 방지)
   - 동영상 정지 (사용자가 닫으면 즉시 정지)
   - 이미지/동영상 전환 시 기존 요소 정리

**사용 시나리오**:
- BNR 소재 클릭 → 정적 이미지 팝업
- VID 소재 클릭 → YouTube 동영상 자동 재생
- ESC 또는 배경 클릭 → 모달 닫기 및 동영상 정지

**테스트 결과**:
- ✅ PHPH.csv: 59개 소재 (파일명 기준)
- ✅ BNR: 23개 (이미지 썸네일 정상 표시)
- ✅ VID: 36개 (플레이 버튼 정상 표시)
- ✅ YouTube 임베드 재생 확인 완료

### ✨ Step 1: 분석 기준 옵션 추가 완료 (이전 업데이트)

**배경**: 사용자가 첨부한 PHPH.csv 파일에 '소재명'(T열)과 '파일명'(S열)이 별도로 존재하지만, 분석 시 하나의 기준으로만 집계되어 다양한 관점의 분석이 불가능했던 문제

**개선사항**:

1. **소재명/파일명 분석 기준 선택 옵션 추가**
   - **소재명 기준**: 광고 카피(Ad Copy) 단위로 집계 
     - 예: "A-Character-Adventure01A-DA"로 묶인 모든 크리에이티브를 하나로 합산
     - 결과: 23개 소재 (동일 카피를 사용하는 다양한 크리에이티브가 통합됨)
   - **파일명 기준**: 크리에이티브 파일 단위로 집계
     - 예: "251104_BNR_A-Character-Adventure01A-DA_L_1200x628_EN.jpg"처럼 고유한 파일별로 분석
     - 결과: 59개 소재 (각 크리에이티브 파일이 독립적으로 분석됨)

2. **CSV 컬럼 매핑 강화**
   - `plNormalizeColumns()` 함수 개선: '소재명'과 '파일명' 컬럼을 모두 보존
   - 기존 문제: BNR/VID 행에서 '파일명' 값이 '소재명'을 덮어쓰는 문제 해결
   - 새로운 로직: 두 컬럼을 독립적으로 유지하여 사용자가 선택 가능

3. **집계 로직 개선**
   - `aggregateCreativeData()` 함수: `groupBy` 파라미터 지원
   - TXT 유형 자동 제외 (BNR/VID만 분석)
   - 선택된 기준에 따라 다른 집계 결과 생성:
     - 전환, 비용, 노출수, 클릭수 합계
     - CPA, IPM, CTR 재계산
     - 태그 및 인사이트는 첫 번째 행 기준으로 유지

4. **UI/UX 개선**
   - 기간 필터 섹션에 분석 기준 라디오 버튼 추가
   - 기준 변경 시 자동 재분석 실행
   - 결과 테이블에 집계 기준 값 표시 (굵은 글씨)
   - 보조 정보(다른 기준 값)는 작은 글씨로 표시

5. **검증 테스트 완료**
   - `test_auto.html`: 자동 테스트 페이지로 두 기준 비교 검증
   - 실제 PHPH.csv 데이터로 테스트:
     - 소재명 기준: 23개 소재 (최고 점수 98.5점, 777전환)
     - 파일명 기준: 59개 소재 (최고 점수 94.7점, 758전환)
     - 차이: 36개 (정상 작동 확인)

**사용 시나리오**:
- **소재명 기준**: 광고 카피의 전반적인 성과를 평가하고 싶을 때
- **파일명 기준**: 특정 크리에이티브 파일의 세부 성과를 추적하고 피로도를 분석하고 싶을 때

**영향**:
- Total Score가 분석 기준에 따라 다르게 계산됨
- 군집화 분석 시 더 세밀하거나 통합적인 관점 선택 가능
- 소재 피로도 분석 시 파일명 기준으로 일자별 순위 변동 추적 가능

### ✨ marketer_insight 키워드 추출 고도화 완료 (이전 업데이트)

**배경**: 기존 인사이트 키워드 추출 로직에서 "높은", "강조", "마케터 의도" 등 분석 용어와 유의미하지 않은 키워드가 추출되어 분석이 왜곡되는 문제 발생

**개선사항**:

1. **대폭 확장된 불용어 사전 (150+ 단어)**
   - 마케팅/분석 메타 용어: "소재", "분석", "결과", "확인", "전략", "방향", "개선", "최적화" 등
   - 일반 형용사/부사: "높은", "낮은", "강한", "많은", "빠른" 등
   - 분석 프레임 키워드: "마케터", "의도", "타겟", "심리", "CVR", "CPA", "전환율" 등
   - 접속사/보조동사: "통해", "따라", "위해", "하기", "되어", "것으로" 등
   - 영어 불용어: "the", "is", "and", "very", "increase", "effect" 등

2. **강화된 메타 정보 필터링**
   - `[마케터 의도]`, `[타겟 심리]` 등 괄호 프레임 자동 제거
   - "전환율 10% 상승 예상", "CVR 2.5% 기대" 등 성과 지표 언급 제거
   - "...으로 판단됨", "...로 예상됨" 등 분석 결론 패턴 제거

3. **엄격한 키워드 품질 검증**
   - 최소 길이: 단일 키워드 4자 이상, 복합 키워드 6자 이상
   - 숫자 비율: 40% 이하만 허용 (기존 50%)
   - 한글/영문 비율: 60% 이상 필수
   - URL 패턴 자동 제외
   - 불용어 60% 이상 구성된 복합어 제외

4. **최종 필터링 강화**
   - 패턴 기반 분석 문구 제외: "예상됨", "판단됨", "보임" 등
   - 성과 메타 단어 제외: "전환율", "CVR", "지표", "수치" 등
   - 소재당 최대 5개 키워드 (기존 6개)로 품질 중시

**결과**: marketer_insight 필드에서 "와이드 뷰 거대 보스 대립", "레이드 콘텐츠 암시", "생존 압박감" 등 **구체적이고 실행 가능한 소재 특성 키워드**만 추출되어 군집화 정확도 향상
