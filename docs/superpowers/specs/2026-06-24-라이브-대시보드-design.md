# 라이브 대시보드 설계 스펙

작성 2026-06-24 · 브레인스토밍 합의 기반.

---

## 0. 한 줄 요약

소재 분석(step1)·군집화(step2)와 **별도의 신규 페이지**. 상단 필터(타이틀·기간·국가·OS·캠페인) + 중단 **통합 추이 그래프**(Google Ads+MMP 합산, 주요 소재 Top N) + 하단 **소재 그리드**(클릭 시 분석 모달). 핵심 목적 = "현재 어떤 소재가 노출 중이고 일자별 노출/획득 추이가 어떻게 변하는가". 순수 프론트엔드(기존 `{title}.json` 소비, 파이프라인 무변경).

---

## 1. 배경 · 목적

- step1(소재 분석)은 소재별 점수·인사이트 중심, step2(군집화)는 태그 군집 중심. **"지금 무엇이 돌고 있고 추이가 어떤가"를 한 화면에 보는 뷰가 없음.**
- 마케터 니즈: 운영 중 소재의 **일별 노출·획득(전환/설치) 추이**를 주요 소재 단위로 빠르게 확인 + 소재 실물(미리보기) + 클릭 시 분석.

---

## 2. 확정 결정 (브레인스토밍 Q&A)

| 항목 | 결정 |
|------|------|
| OS·국가 필터 | `campaign_name`에서 **파싱**(국가 US/CA/SEA/PH, OS iOS 등). 토큰 없으면 '미상' graceful |
| 그래프 레이어 | **통합 단일 곡선** — Google Ads 전환 + MMP 설치 = '획득', 노출도 합산. (MMP가 Google 채널 제외 수집 → 비중복) |
| 그래프 지표 | 토글 **노출 / 획득 / CPI** |
| Top N 기준 | **획득 상위** (5~10, 조절 가능) |
| 페이지 이름 | **라이브 대시보드** (네비 4번째 항목) |
| 그리드 범위 | **모든 소재 표시**(노출 유무 무관 — 광고 집행 전에도 확인). 필터는 그래프(추이)를 스코프 |
| 대상 타이틀 | 그래프는 KPI 연동 타이틀(펩). 그리드+모달은 미연동(도원암귀) 포함 전 타이틀 동작 |

## 3. 아키텍처

```
live_dashboard.html  (신규 — step1/step2와 동일한 독립 HTML 패턴)
  ├─ <head>: cl-shell.css(공용 헤더) + Chart.js 4.4.0(CDN, step1과 동일) + data-source.js + layer-metrics.js (?v= 버전쿼리)
  ├─ 공용 헤더(.cl-topbar) — 네비에 "라이브 대시보드" active 추가 (4개 HTML 헤더 동기)
  ├─ ① 필터 바  (타이틀·기간·국가·OS·캠페인)
  ├─ ② 통합 추이 그래프 (Chart.js 라인, 지표 토글, Top N)
  └─ ③ 소재 그리드 (카드: 소재명+미리보기 → 클릭 시 분석 모달)

데이터 흐름:
  titles.json(매니페스트) → {title}.json(data-source.js 로드)
    → campaign_name 파싱으로 국가/OS 옵션 도출
    → 필터 적용(일별 엔트리 단위) → 소재별 일별 통합 시리즈 산출
    → 그래프(Top N) + 그리드(노출>0 소재) 렌더
```

**파이프라인 변경 없음.** 모든 입력은 기존 `kpi_daily`/`mmp_daily`(일별·campaign_name 포함).

## 4. 컴포넌트 상세

### 4-A. 필터 바

| 필터 | 소스 | 동작 |
|------|------|------|
| 타이틀 | `titles.json` 매니페스트 | 선택 시 해당 `{title}.json` 로드 |
| 기간 | 날짜 프리셋(7/14/21/28/전체/직접) | 실적일(`kpi_daily.date`/`mmp_daily.date`) 범위 |
| 국가 | `campaign_name` 파싱 | 멀티선택, '미상' 포함 |
| OS | `campaign_name` 파싱 | 멀티선택, '미상' 포함 |
| 캠페인 | `campaign_name` 원문 | 멀티선택 |

**campaign_name 파싱 규칙** (예: `HQ_HQ_PH_US-EN_GA_NU_AD_ACA-PU_260429`, `HQ_HQ_PH_CA-EN_FB_NU_iOS_INSTALL_260122`):
- **국가**: `_`로 분할한 세그먼트 중 `^[A-Z]{2,4}-[A-Z]{2}$` 패턴(US-EN/CA-EN/SEA-EN/PH-EN)을 찾아 `-` 앞부분 추출. 없으면 '미상'.
- **OS**: 세그먼트 중 `iOS`/`AOS`/`Android`/`Web`(대소문자 무시) 매칭. 없으면 '미상'.
- 방어적: 규칙 미스 → 해당 차원 '미상'(소재는 버리지 않음).

필터는 **일별 엔트리 단위**로 적용 — 한 소재가 여러 캠페인(국가/OS)에 걸쳐 있으면, 필터에 맞는 엔트리만 집계에 포함.

### 4-B. 통합 추이 그래프 (Chart.js 라인)

**통합 일별 집계** — 선택 필터·기간 내, 소재별·일자별로 `kpi_daily`(Google Ads) + `mmp_daily`(MMP) 합산:
- **노출** = Σ kpi.impressions + Σ mmp.impressions
- **획득** = Σ kpi.conversions + Σ mmp.installs  (비중복: MMP가 Google 채널 제외)
- **비용** = Σ kpi.cost + Σ mmp.cost  (※ 통화 정규화 — 기존 대시보드 관례 따름: MMP USD×`mmp_fx_rate`. Google Ads cost 통화 단위는 구현 시 확인 후 동일 통화로 합산)
- **CPI** = 비용 / 획득  (획득 0인 날은 결측/gap)

**렌더**:
- 지표 토글(노출/획득/CPI) — 선택 지표를 Y축으로.
- **Top N 소재**(기본 7, 슬라이더/셀렉트로 5~10) = 필터 기간 **획득 합계 상위** N개. 각 소재 = 1개 라인(일자별 시리즈).
- X축 = 일자(기간 내), 범례 = 소재명. Com2uS DS 색.
- 데이터 0건(필터 결과 없음) → 빈 상태 안내.

### 4-C. 소재 그리드 + 분석 모달

- **그리드**: 선택 타이틀의 **모든 소재**를 카드로 — **노출 유무와 무관**(광고 집행 전·필터 기간 노출 0인 소재도 항상 표시). 카드 = **소재명 + 미리보기**만(컴팩트).
  - 미리보기: 이미지 썸네일 / 영상 / 없으면 📷 또는 Drive 폴백(직전 작업 `currentDriveFolderUrl` 동일 로직 재사용).
  - 정렬: 필터 기간 **획득 상위순**(노출/획득 없는 소재는 뒤로 — 단 숨기지 않음).
  - **필터(국가/OS/캠페인/기간)는 그래프(추이)를 스코프 — 그리드 카드는 숨기지 않음**(집행 전 확인이 목적). 각 카드에 필터 기간 획득을 작은 배지로 표시(없으면 '—').
- **클릭 → 분석 모달**: step1의 소재 상세 모달과 **동일한 분석 내용**(creator_intent·one_line_insight·강점/약점+근거·신호칩·지표). 
  - **공용화 원칙**: 두 페이지가 동일 분석을 보이도록 — 구현 시 step1 모달 빌더(`buildInsightBlocksHtml`/`buildSignalChipsHtml`/`mmpStdMetrics` 등, 현재 step1 line 2151~2230 헬퍼)를 **공용 모듈로 추출하거나 동등 재현**. **하드 제약: step1 무회귀**(추출이 위험하면 신규 페이지 자체 모달로 동등 재현, 분석 표시 내용은 동일).

### 4-D. KPI 미연동 graceful

- 로드한 `{title}.json`에 `kpi_daily`/`mmp_daily` 활동이 전무하면(도원암귀) → **그래프 영역만** "이 타이틀은 운영(KPI) 데이터가 없어 추이를 표시할 수 없습니다" 안내. **그리드는 그대로 소재 표시**(소재명·미리보기·분석 모달은 KPI 없이도 유효) → 집행 전/미연동 타이틀도 소재 브라우징+분석 가능. 국가/OS/캠페인 필터는 옵션 없음(비활성). step1의 KPI 미연동 감지(`!_hasKpi && !_hasMmp`)와 동일 기준.

## 5. 데이터 처리 요약

```
loadTitle(titleId)
  rows = data-source.loadCreativeData(...)            # {title}.json
  for each creative c:
    dailies = (c.kpi_daily 매핑 'GA') + (c.mmp_daily 매핑 'MMP')
    each daily d: d.country = parseCountry(d.campaign_name)
                  d.os      = parseOS(d.campaign_name)
  countryOptions / osOptions / campaignOptions = distinct(파싱 결과)

applyFilters(period, countries, oses, campaigns):
  filteredDailies = dailies where date∈period ∧ country∈sel ∧ os∈sel ∧ campaign∈sel
  perCreativePerDay = group(filteredDailies, by [creative, date]) → {impr, acq, cost}
                       impr = Σimpressions, acq = Σ(conversions|installs), cost = Σcost
  topN = creatives(노출 데이터 보유) sorted by Σacq desc, take N
  chart = lines(topN, metric)                         # 노출/획득/CPI
  grid  = ALL creatives (노출 무관 — 집행 전 포함), sorted by Σacq desc (무데이터 뒤로)
```
