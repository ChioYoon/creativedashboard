# 성과 요약 리포트 (Summary Report) 설계

**작성일:** 2026-07-06

## Goal

대시보드의 분석 결과를 **큐레이션된 1장 요약**(핵심 KPI·Top 소재·유형 요약·인사이트)으로 원클릭 생성해, 주기 보고·발표·공유에 바로 쓰도록 한다. 기존 "HTML 추출"(전체 소재 테이블 덤프)과 달리 요약·발표용이다.

## 배경 / 기존과의 차이

`exportResultHTML`(step1_integrated.html:5343)은 전체 소재를 행으로 나열하는 **상세 테이블 덤프**(기록·검토용)라 주기 보고에 부적합하다. 마케터는 매 보고마다 핵심 지표·top 소재를 수작업으로 요약한다. 본 기능은 그 요약을 자동 생성한다. 형식은 기존 export와 같은 **자체 완결 HTML**이지만 내용은 정반대(전체 테이블 → 큐레이션 요약).

## Architecture (접근법 A)

결과 툴바(`#resultToolbar .rt-right`, 기존 "HTML 추출"·"제작 브리프 추출" 버튼 옆)에 **"요약 리포트" 버튼**을 추가한다. 클릭 시 신규 함수 `exportSummaryReport()`가 `window.currentCreatives`와 기존 집계 로직에서 요약을 조립해 **자체 완결 HTML 문자열**을 만들고, 기존 export와 동일한 Blob 다운로드로 저장한다. HTML은 인라인 CSS + `@media print` + 내장 "인쇄" 버튼을 포함해, 열어서 원클릭 PDF(브라우저 인쇄) / 캡처로 이미지를 얻는다.

접근법 후보: A(독립 HTML 다운로드, 기존 패턴) / B(새 탭 window.open, 팝업 차단 리스크) / C(페이지 내 @media print 격리, 복잡 페이지에서 취약). **A 채택** — 검증된 export 메커니즘 재사용, 팝업 무관, 무의존.

## 리포트 내용 (한 장)

1. **헤더** — 타이틀명, 기간(`startDate`~`endDate` 값, 없으면 "전체 기간"), 레이어(`window.currentAnalysisLayer` → "Google Ads 기준"/"MMP 기준"), 생성일시.
2. **KPI 요약 카드** (5개):
   - 소재 수 = `currentCreatives.length`
   - 평균 점수 = 활성 레이어 데이터 보유 소재 점수 평균 (updateStatCards의 statAvg 로직: mmp면 mmp_quality_score.total, ads면 TotalScore)
   - 최우수 수 = 등급 '최우수' 개수 (statExcellent 로직)
   - 개선필요 수 = 등급 '개선필요' 개수 (statPoor 로직)
   - 총 전환(basis) = Σ `creativeLayerView(c).전환` (라벨은 `detectConversionBasis()` → "총 전환(사전예약)" 등)
3. **Top 5 성과 소재** — `TotalScore` 내림차순 상위 5개(ads 데이터 보유: `_ads.imp > 0`). 각 행: 썸네일(`c.이미지링크`), 소재명(`c.key`), 전환·CPA·점수, 등급 배지.
4. **유형별 요약** — `aggregateTypeMetrics(currentCreatives)` + `typeBlended`로 BNR/VID별 소재 수·평균 점수 표. (기존 renderTypeSummaryTable과 동일 데이터, 요약본만.)
5. **인사이트** — `#scoringAIBox`에 생성된 AI 인사이트가 있으면(비어있지 않으면) 그 내용을 요약 스타일로 포함, 없으면 섹션 생략.

## 데이터 소스 (전부 기존 재사용)

- `window.currentCreatives` (분석·정렬된 소재; 현재 필터·기간·레이어 반영)
- `detectConversionBasis()` — 전환 기준 라벨
- `aggregateTypeMetrics()` / `typeBlended()` — 유형 집계
- 통계 계산 로직 (updateStatCards, 2316행 부근) — 평균/최우수/개선필요
- `creativeLayerView(c)` — 활성 레이어 지표(전환 등)
- `#scoringAIBox` innerHTML/textContent — AI 인사이트(있을 때)

## 리포트 HTML 구조 / 기술

- 자체 완결 HTML(`<!DOCTYPE html>...`) 문자열, 모든 스타일 인라인 `<style>`(외부 의존 없음 — 오프라인·공유 가능).
- `@media print { ... }` 로 인쇄 시 여백·페이지 최적화, "인쇄" 버튼은 `@media print`에서 숨김.
- 상단에 `<button onclick="window.print()">인쇄 / PDF 저장</button>` 내장.
- Blob + `URL.createObjectURL` + 임시 `<a download>` 클릭으로 저장(기존 exportResultHTML과 동일 다운로드 패턴).
- 파일명: `성과요약_<타이틀>_<YYYYMMDD_HHMM>.html`.

## Error Handling / Edge Cases

- `currentCreatives` 없음/빈 배열 → `alert('분석 결과가 없습니다. 점수 계산을 먼저 실행해 주세요.')` 후 return (기존 export와 동일 가드).
- 활성 레이어 데이터 보유 소재 0 → 평균 점수 '—', Top 소재 섹션 "데이터 없음" 표시.
- AI 인사이트 미생성(`#scoringAIBox` 비어있음) → 인사이트 섹션 생략(빈 섹션 표시 안 함).
- 썸네일 `c.이미지링크` 없음 → 유형 약자(BNR/VID) placeholder.
- Top 5 미만(소재 5개 미만) → 있는 만큼만 표시.

## Testing / Verification

정적 사이트 → preview(브라우저) 기반:
1. zeus 분석 실행 → "요약 리포트" 버튼 클릭 → HTML 다운로드 발생(파일명 규칙 확인).
2. 생성된 HTML 구조 검증: 헤더(타이틀·기간·레이어), KPI 카드 5개(값이 통계칩과 일치), Top 5 소재(테이블 상위와 일치·썸네일), 유형 요약(aggregateTypeMetrics 값과 일치), 인사이트(생성했으면 포함/안 했으면 생략).
3. 인쇄 미리보기(또는 print CSS) 레이아웃이 1~2장으로 깔끔한지 확인.
4. 데이터 없을 때 alert 가드 동작.

## Out of Scope (YAGNI)

- 실제 .pptx/.pdf 파일 생성 (HTML 인쇄→PDF로 대체).
- 다중 타이틀 통합 리포트 (현재 뷰 단일 타이틀만).
- 이메일/Slack 자동 발송·스케줄링 (수동 공유).
- 리포트 항목 커스터마이징 UI (고정 구성).
- 기간 자동 비교(전주 대비 등) — 이번 범위 밖(향후 "분석 심화" 방향에서 검토).
