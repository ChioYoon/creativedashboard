# 라이브 대시보드 — 필터 드롭다운 통합 설계

**작성일:** 2026-07-02
**대상:** `live_dashboard.html`(CSS), `js/live-dashboard.js`(`LIVE.buildFilters`)
**요구:** 국가·OS·유형·매체·상품·캠페인 필터가 인라인 체크박스 나열이라 값이 늘면 줄바꿈이 많아지고 검색·선택이 어려움. 검색 가능한 드롭다운 멀티셀렉트로 통일.

## 현황

- `LIVE.buildFilters`([js:78-147](js/live-dashboard.js)): `checks(name, arr)`가 각 값을 인라인 `<label><input type=checkbox>`로 나열 — 국가/OS/유형/매체/상품 전부 이 방식, 검색·접기 없음.
- **캠페인만 예외적으로** 검색(`#liveCampSearch`)+전체선택/해제+스크롤(`#liveCampList` max-height:80px)을 이미 갖춤([js:106-146](js/live-dashboard.js)).
- 스크린샷 확인: 값이 몇 개만 늘어도(제우스는 국가/OS "미상"뿐인데도) 필터 바가 가로로 넓게 퍼짐 — 값이 많은 타이틀에서는 더 심해짐.

## 설계 — 통일된 드롭다운 멀티셀렉트

기존 캠페인 패턴을 **모든 그룹 필터(국가·OS·유형·매체·상품·캠페인)에 일반화**해 재사용 컴포넌트로 추출.

### 컴포넌트 구조 (신규 `ddGroup(name, label, arr)`)
```html
<div class="live-filter-group live-dd" data-dd-name="{name}">
  <label>{label}</label>
  <button type="button" class="live-dd-btn" data-dd-trigger="{name}">전체 ▾</button>
  <div class="live-dd-panel" data-dd-panel="{name}">
    <input type="text" class="live-dd-search" data-dd-search="{name}" placeholder="검색…">
    <div class="live-dd-actions">
      <button data-dd-all="{name}" data-dd-select="1">전체선택</button>
      <button data-dd-all="{name}" data-dd-select="0">해제</button>
    </div>
    <div class="live-dd-list" data-dd-list="{name}">
      <label><input type="checkbox" data-filter="{name}" value="v">v</label> ...
    </div>
  </div>
</div>
```

### 동작
- **트리거 버튼**: 기본 "전체 ▾", 선택 있으면 "N개 선택 ▾"(선택 시 브랜드 레드 테두리로 강조). 클릭 시 자신의 패널 토글, 다른 패널은 닫음.
- **패널**: 절대 위치 팝오버(트리거 버튼 아래), 검색 입력 + 전체선택/해제(현재 검색으로 보이는 항목만 대상, 기존 캠페인 로직과 동일) + 스크롤 가능한 체크박스 리스트(max-height 220px).
- **바깥 클릭** 시 모든 패널 닫힘(document 리스너, 중복 등록 방지 가드).
- **체크박스 변경** → `LIVE.state.filters[name]` Set 갱신 → 트리거 라벨 갱신(리렌더 없이) → `LIVE.render()`.
- 값 0개인 그룹(예: `hasCanon=false`일 때 유형/매체/상품)은 기존처럼 렌더 생략.

### 기간(period) 필터
프리셋 버튼+날짜 입력은 체크박스 리스트가 아니므로 **드롭다운 미적용, 현행 유지**.

## 불변

- `LIVE.state.filters` 키·Set 구조·`LIVE.render()`/`applyFilters()`/집계 로직 전혀 변경 없음. **UI 컴포넌트만 교체.**
- 데이터 기준 배지(직전 작업)·미집행 배지 로직 무관.

## 검증 (preview)

`live_dashboard.html?title=zeus&_=<ts>`:
1. 국가/OS/유형/매체/상품/캠페인 6개 그룹 모두 `.live-dd-btn` 트리거로 렌더(체크박스 인라인 나열 없음).
2. 트리거 클릭 → 패널 열림(`.live-dd-panel.open`), 다른 트리거 클릭 → 이전 패널 닫힘.
3. 검색 입력 시 리스트 필터링, 전체선택/해제가 보이는 항목만 대상.
4. 체크박스 선택 → 트리거 라벨 "N개 선택" 갱신 + `LIVE.render()` 호출(그래프/그리드 반영).
5. 바깥 클릭 → 패널 닫힘.
6. 콘솔 error 0.
