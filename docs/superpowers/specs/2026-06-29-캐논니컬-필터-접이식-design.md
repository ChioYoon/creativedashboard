# 캐논니컬 캠페인 유형 필터 — 접이식 그룹 UI 설계

**작성일:** 2026-06-29
**대상:** `step1_integrated.html` — `populateCanonicalFilter` / `onCanonicalChange` + 신규 토글 함수

## 목표

캐논니컬 캠페인 유형 필터의 각 차원(캠페인 목적·국가·OS·매체·상품)을 **접이식 그룹(아코디언)**으로 바꿔, 차원·값 수가 늘어도 사이드바 높이가 일정하게 유지되도록 한다. 현재는 모든 차원의 체크박스가 펼쳐져 세로로 쌓여 사이드바 스크롤이 무한정 길어진다.

표시 방식만 바꾸고 **필터 동작·데이터·조인 로직은 변경하지 않는다.**

## 범위

**대상 (in scope)**
- `populateCanonicalFilter()` (약 4190행) — 차원별 렌더를 헤더(접기/펼치기) + 접힌 콘텐츠로 변경.
- `onCanonicalChange()` (약 4209행) — 선택수 배지 갱신 추가.
- 신규 `toggleCanonGroup(key)` — 그룹 펼침/접힘 토글.

**비대상 (out of scope) — 무변경**
- 필터 판정 로직: `resolveCanonicalCampaigns`, `resolveCanonicalAllowed`(js/canonical-filter.js), `refreshCampaignVisibility`.
- 캠페인 검색/체크박스 목록(`campaignSearchInput`, `campaignCheckboxGroup`), 그 외 사이드바 필터.
- 데이터·파이프라인.

## 설계

### 렌더 — `populateCanonicalFilter`

차원별 HTML을 아래 구조로 생성한다(기존 인라인-스타일 컨벤션 유지). `opts` = 기존 체크박스 묶음(현행과 동일, `data-canon`·`onchange="onCanonicalChange()"`).

```js
host.innerHTML = CANON_DIMS.map(d => {
  const opts = [...values[d.key]].sort().map(v =>
    `<label style="display:inline-flex;align-items:center;gap:3px;font-size:11px;margin:0 6px 4px 0;cursor:pointer;">` +
    `<input type="checkbox" data-canon="${d.key}" value="${v}" onchange="onCanonicalChange()" style="margin:0;">${v}</label>`).join('');
  return `<div style="margin-bottom:4px;border-bottom:1px solid #f1f1f1;">
    <div onclick="toggleCanonGroup('${d.key}')" style="display:flex;align-items:center;justify-content:space-between;cursor:pointer;padding:5px 0;">
      <span style="font-size:11px;font-weight:700;color:#6b7280;">${d.label}</span>
      <span style="display:flex;align-items:center;gap:5px;">
        <span id="canonCount_${d.key}" style="display:none;font-size:10px;background:#eef2ff;color:#4f46e5;border-radius:5px;padding:0 6px;line-height:1.5;"></span>
        <span id="canonChevron_${d.key}" style="font-size:10px;color:#9ca3af;">▸</span>
      </span>
    </div>
    <div id="canonGroup_${d.key}" style="display:none;max-height:120px;overflow-y:auto;padding:2px 0 5px;">${opts}</div>
  </div>`;
}).join('');
```

- **기본 전부 접힘**: 콘텐츠 div `display:none`. populate 가 재호출될 때마다 새로 그려지므로 항상 접힌 상태로 시작.
- **값 많은 차원**: 콘텐츠 `max-height:120px; overflow-y:auto` → 펼쳐도 내부 스크롤로 높이 고정.

### 토글 — 신규 `toggleCanonGroup(key)`

```js
function toggleCanonGroup(key) {
  const c = document.getElementById('canonGroup_' + key);
  const ch = document.getElementById('canonChevron_' + key);
  if (!c) return;
  const open = c.style.display !== 'none';
  c.style.display = open ? 'none' : '';
  if (ch) ch.textContent = open ? '▸' : '▾';
}
```

상태는 DOM(콘텐츠 div의 display)에서 직접 읽으므로 별도 상태 객체 불필요.

### 선택수 배지 — `onCanonicalChange` 보강

기존 로직(currentCanonical 갱신 + `refreshCampaignVisibility()`) 끝에 배지 갱신을 추가한다.

```js
CANON_DIMS.forEach(d => {
  const badge = document.getElementById('canonCount_' + d.key);
  if (!badge) return;
  const n = currentCanonical[d.key].size;
  badge.textContent = String(n);
  badge.style.display = n > 0 ? '' : 'none';
});
```

`#canonicalFilterGroups input:checked` 초기화(약 6106행, "전체 해제") 시에도 배지가 0으로 비도록, 해제 후 `onCanonicalChange()`가 호출되는지 확인 — 호출되지 않으면 배지 갱신 루프를 동일하게 적용한다.

## 검증 (preview 기반)

`preview_eval`/screenshot 으로 확인(합성 `window.__campaignCanonical` 주입 후 `populateCanonicalFilter()` 호출):

1. **렌더**: 차원별 헤더 + chevron `▸`(접힘) + 콘텐츠 `display:none`. 전체 높이가 상품 값 수와 무관하게 일정.
2. **토글**: 헤더 클릭(`toggleCanonGroup('product')`) → 콘텐츠 표시 + chevron `▾`. 재클릭 → 접힘.
3. **내부 스크롤**: 상품(값 8+) 펼침 시 콘텐츠 `max-height:120px` + 스크롤.
4. **선택수 배지**: 체크 → 해당 차원 배지 숫자 표시(>0), 해제 → 숨김.
5. **무회귀**: 체크 시 `resolveCanonicalCampaigns()`/`refreshCampaignVisibility()` 동작 동일(캠페인 목록 좁혀짐). 콘솔 error 0.

## 비목표 (non-goals)

- 필터 판정·캠페인 검색·데이터 로직 변경 없음(표시 방식만).
- 선택 차원 자동 펼침 없음(기본 전부 접힘 — 선택은 배지로 표시).
- 신규 CSS 파일/클래스 없음(기존 인라인 스타일 컨벤션 유지).
