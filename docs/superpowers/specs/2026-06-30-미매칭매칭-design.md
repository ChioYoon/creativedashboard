# 미매칭 소재 매칭 — 패널 접기 + 완전 병합 파일 생성 설계

**작성일:** 2026-06-30
**대상:** `step1_integrated.html` — `renderUnmatchedPanel`(4158), `buildAliasConfig`(4193)
**요구:** ① 미매칭 집행 소재 패널을 기본 접기 상태로. ② 매칭 반영을 더 편리하게 — 조각(snippet) 대신 **완전한 병합 파일** 생성 + 다운로드, 그리고 생성물을 Claude에게 전달해 로컬 반영하는 경로.

## 결정 요약

「**완전 병합 파일 생성 + Claude 반영 경로**」(사용자 선택).
- 현재 `buildAliasConfig`는 `{[titleId]:{_creative_name_aliases}}` **조각**만 출력 → 사용자가 수동 병합 시 JSON 깨짐·기존 설정(`pepp-us` 등) 덮어쓰기 위험.
- 개선: 현재 `js/titles_overrides.json`을 fetch→딥 병합→**전체 유효 JSON** 출력(복사+다운로드). 적용은 (1) 로컬 파일 교체+커밋, 또는 (2) Claude에게 전달해 반영 요청.

## 현황(컨텍스트)

- `renderUnmatchedPanel`(4158): `window.__unmatchedAssets`가 있으면 경고 박스(항상 펼침) — 표(자산/소스/노출/비용/유형/매핑 select) + "별칭 config 생성·복사" 버튼 + `<pre id="aliasConfigOut">`.
- `buildAliasConfig`(4193): 선택된 매핑으로 `{[titleId]:{_creative_name_aliases:{concept:소재명}}}` 조각 생성 + 클립보드 복사.
- 매칭 메커니즘: 야간 파이프라인이 **로컬** `js/titles_overrides.json`의 `_creative_name_aliases`(집행명→정규 소재명)를 읽어 조인.
- 파일 구조(현재): `{ "pepp-us": { "_pipeline_google_ads_window_days":159, "_pipeline_kpi_start_date":"2025-11-01" } }`. 타이틀별 객체에 `_creative_name_aliases`·`_pipeline_*` 키 공존.
- 정적 사이트(백엔드 없음) → 브라우저는 파일을 직접 저장 불가. 적용엔 파일 교체+커밋 필요.

## Part 2 — buildAliasConfig: 완전 병합 파일 + 다운로드

`buildAliasConfig`(4193-4204)을 async 로 교체 + `downloadAliasConfig` 신규:
```js
    // 선택 매핑을 현재 titles_overrides.json 에 딥 병합해 '완전한 파일' 생성 (기존 설정·타 타이틀 보존)
    async function buildAliasConfig() {
      const sels = document.querySelectorAll('#unmatchedPanel select[data-unmatched-concept]');
      const aliases = {};
      sels.forEach(s => { if (s.value) aliases[s.dataset.unmatchedConcept] = s.value; });
      const out = document.getElementById('aliasConfigOut');
      if (!Object.keys(aliases).length) { out.style.display = ''; out.textContent = '매핑 대상을 1건 이상 선택하세요.'; return; }
      const titleId = (window.DataSource && DataSource.getActiveTitleId && DataSource.getActiveTitleId()) || '<title>';
      let current = {}, fetchOk = false;
      try {
        const res = await fetch('js/titles_overrides.json', { cache: 'no-store' });
        if (res.ok) { current = await res.json(); fetchOk = true; }
      } catch (_) {}
      const merged = { ...current };
      const prevTitle = merged[titleId] || {};
      const prevAliases = prevTitle._creative_name_aliases || {};
      merged[titleId] = { ...prevTitle, _creative_name_aliases: { ...prevAliases, ...aliases } };
      const fullJson = JSON.stringify(merged, null, 2);
      window._aliasConfigJson = fullJson;
      const note = fetchOk
        ? `// js/titles_overrides.json 전체를 아래 내용으로 교체하세요 (기존 설정 모두 포함됨).\n// 또는 이 내용을 Claude에게 전달하면 로컬 파일에 반영+커밋해 드립니다.\n`
        : `// ⚠️ 현재 설정 파일을 읽지 못해 이 타이틀 별칭만 포함됩니다. 기존 파일에 병합하거나 Claude에게 전달하세요.\n`;
      out.style.display = ''; out.textContent = note + fullJson;
      if (navigator.clipboard) navigator.clipboard.writeText(fullJson).catch(() => {});
    }

    // 생성된 완전 파일을 titles_overrides.json 으로 다운로드
    function downloadAliasConfig() {
      const out = document.getElementById('aliasConfigOut');
      const json = window._aliasConfigJson;
      if (!json) { if (out) { out.style.display = ''; out.textContent = '먼저 "매핑 반영 파일 생성"을 누르세요.'; } return; }
      const blob = new Blob([json], { type: 'application/json' });
      const url = URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url; a.download = 'titles_overrides.json';
      document.body.appendChild(a); a.click(); document.body.removeChild(a);
      setTimeout(() => URL.revokeObjectURL(url), 1000);
    }
```

## 딥 병합 규칙

- 최상위: 기존 `current`의 모든 타이틀 보존(`{...current}`).
- 활성 타이틀: 기존 키(`_pipeline_*` 등) 보존(`{...prevTitle}`), `_creative_name_aliases`만 기존+신규 병합(`{...prevAliases, ...aliases}`).
- 결과는 항상 유효한 전체 JSON → 그대로 교체 가능.

## 불변(반드시 유지)

- 매칭 로직·야간 파이프라인·점수·집계 전혀 변경 없음. UI(접기) + 생성물 품질(전체 파일·안전 병합)만 개선.
- 매핑 select·표 구조·`__unmatchedAssets` 데이터 흐름 무변경.

## 엣지 케이스

- 미매칭 0건 → 패널 숨김(기존 동작 유지).
- fetch 실패(file:// 등) → `fetchOk=false`, 이 타이틀 별칭만 포함 + 경고 note. (서빙 환경에선 정상 fetch.)
- 매핑 미선택 → "1건 이상 선택" 안내.
- 다운로드 전 생성 안 함 → "먼저 생성하세요" 안내.
- titles_overrides.json 파싱 실패(손상) → fetch는 ok지만 `res.json()` throw → catch로 current={} fallback(경고 note는 fetchOk=true라 안 뜸) — 손상 파일은 드묾, 허용.

## 비목표(이번 제외)
