# CLOOP 대시보드 리디자인 스펙
작성 2026-06-17 · 브레인스토밍 세션 기반 확정

---

## 1. 목표

Com2uS 디자인 시스템을 적용하여 CLOOP 대시보드 전체 UI를 재구성한다.  
세 가지 핵심 방향:

1. **Com2uS 디자인 시스템 준수** — 토큰(색상·타이포·간격), 컴포넌트, 브랜드 규칙 일괄 적용
2. **텍스트 최소화** — 인라인 설명 → 호버 툴팁, 이모지 전면 제거, 섹션 레이블 압축
3. **스크롤 축소** — 사이드바 레이아웃 + 탭 구조로 세로 스크롤 제거

---

## 2. 디자인 시스템 적용 규칙

### 2.1 컬러 토큰

| 용도 | 토큰 | 값 |
|---|---|---|
| 브랜드 강조·CTA | `--brand-primary` | `#DC2828` |
| 기본 텍스트 | `--text-primary` | `#191919` |
| 보조 텍스트 | `--text-secondary` | `#666666` |
| 기본 배경 | `--bg-base` | `#FFFFFF` |
| 페이지 워시 | `--surface-soft` | `#FAF9F7` |
| 카드 배경 | `--surface-card` | `#F4F2EF` |
| 구분 면 | `--surface-sink` | `#ECEAE6` |
| 구분선 | `--border-default` | `#CCCCCC` |
| 따뜻한 구분선 | `--hairline-warm` | `#E4E1DC` |

> COM2US Red는 강조·CTA·활성 상태에 한정 사용. 넓은 면적 채움 금지.

### 2.2 타이포그래피

- 전체 서체: **Noto Sans KR** (Google Fonts CDN) + Pretendard 자체 호스팅 폴백
- 기존 시스템 기본 폰트(sans-serif) 전면 교체
- 이모지 전면 제거 (브랜드 가이드라인: 이모지 미사용)
- 아이콘: **Lucide** CDN (라인 아이콘, `currentColor`)

### 2.3 컴포넌트

- **테이블**: `ds-table` 규격 — uppercase 헤더(12px, 자간+0.04em), 헤어라인 행 구분, 세로줄 없음, 숫자 우측 정렬 + tabular-nums, hover 시 `--surface-soft`
- **버튼**: Primary(Red), Secondary(테두리 Red), Tertiary(투명) 3종. 높이 36px(S)/40px(M)/48px(L)
- **배지/칩**: `--radius-full` 캡슐형. 상태별 색상(등급·피로도·유형)
- **카드**: 배경 White, 테두리 1px `--border-default` 또는 그림자(동시 사용 금지), `--radius-md`~`--radius-lg`
- **모달**: `--shadow-modal`, `--radius-lg`

## 3. 레이아웃 구조

### 3.1 전체 구조

```
┌─────────────────────────────────────────────┐
│  TOP NAV BAR (44px, COM2US Red)              │
├──────────────┬──────────────────────────────┤
│              │  분석 레이어 바 (36px)          │
│  SIDEBAR     ├──────────────────────────────┤
│  (240px,     │  탭 바 (36px)                 │
│   접기 가능)  │  소재목록 / 전체성과요약 / 피로도│
│              ├──────────────────────────────┤
│              │  탭 콘텐츠 (스크롤)             │
└──────────────┴──────────────────────────────┘
```

### 3.2 상단 네비게이션 바

- 배경: `--brand-primary` (#DC2828)
- 좌: Com2uS Smile 로고 + "CLOOP" 워드마크 + 서브타이틀 "광고 소재 분석 대시보드"
- 우: 아이콘 버튼 (설정, 도움말 등)

### 3.3 사이드바 (Collapsible)

**펼침 상태**: 240px 고정 너비  
**접힘 상태**: 40px 아이콘 레일 (각 섹션 아이콘만 노출)  
**토글**: 상단 "◀ 접기 / ▶ 펼치기" 버튼

사이드바 섹션 구성 (아코디언, 각 섹션 접기/펼치기 가능):

```
사이드바
├── [데이터] 섹션
│   └── 업로드 상태 표시 (완료 시 파일명 + 초기화 버튼)
│       미완료 시: 드래그앤드롭 또는 클릭 업로드 영역
│
├── [필터] 섹션
│   ├── 기준: 소재명 / 파일명 (라디오)
│   ├── 소재 유형: BNR / VID (칩 멀티셀렉트)
│   ├── 캠페인: 검색 가능 드롭다운
│   ├── 날짜 범위: 시작일 ~ 종료일
│   └── 저노출·저전환 소재 제외 [토글 스위치]
│
├── [가중치] 섹션
│   ├── 전환수 슬라이더 (기본 25%)
│   ├── CPA 슬라이더 (기본 25%)
│   ├── IPM 슬라이더 (기본 25%)
│   ├── ROAS 슬라이더 (기본 25%)
│   └── ROAS 모드: 자동 / 제외 / 끄기 (칩 단일선택)
│
└── [점수 계산 실행] Primary 버튼 (전체 너비)
```

## 4. 메인 콘텐츠 영역

### 4.1 분석 레이어 바

결과 표시 후 노출 (MMP 데이터 보유 타이틀에서만):

- **[Google Ads 기준]** / **[MMP 품질 기준]** 토글
- 기본: Google Ads 기준 (Red 강조)
- MMP 선택 시: MMP 품질점수 기준 정렬, Teal 강조
- 우측: 정렬 기준 드롭다운 + 내보내기 버튼

### 4.2 탭 구조

탭 3개 (결과 존재 시 노출):

| 탭 | 내용 |
|---|---|
| **소재 목록** | 소재 상세 테이블 (기존 결과 테이블) |
| **전체 성과 요약** | 유형별 비교 + 교차 성과 + AI 태그 |
| **피로도** | 기간 설정 + CPA 변화율 피로도 테이블 |

## 5. 탭 상세 스펙

### 5.1 소재 목록 탭

기존 결과 테이블을 `ds-table` 규격으로 재구성:

- 헤더: uppercase 12px, `--bg-subtle` 배경
- 컬럼 설명 라벨 제거 → 헤더 우측 `(?)` 아이콘 호버 툴팁으로 이동
- 활성 1위 행: 좌측 3px Red 인디케이터
- 컬럼 순서: 미리보기 | 소재명 | 유형 | 전환 | CPA | IPM | ROAS | 총점 | 등급 | 성과백분위 | MMP품질 | 추이
- 숫자 컬럼: 우측 정렬 + tabular-nums
- MMP 품질 배지: Teal 계열 캡슐

### 5.2 전체 성과 요약 탭

3개 블록으로 구성:

**블록 1 — 유형별 평균 성과**
- `ds-table` 형식
- 컬럼: 유형 | 소재수 | 평균 전환 | 평균 CPA | 평균 IPM | 평균 총점 | MMP 품질점수
- 요약 KPI 카드 없음

**블록 2 — Google Ads × MMP 품질 교차 성과**
- 2열 카드: "두 지표 모두 우수" / "두 지표 모두 저조"
- 각 카드: 소재명 + Google Ads 점수 배지(Red) + MMP 품질점수 배지(Teal)
- **우수 기준**: Google Ads 종합점수 상위 30% AND MMP 품질점수 상위 30%
- **저조 기준**: Google Ads 종합점수 하위 30% AND MMP 품질점수 하위 30%
- 최대 표시: 우수·저조 각 5개 (점수 기준 정렬)

**블록 3 — AI 태그**
- 강점 / 약점 2개 카드
- 태그: 캡슐형 칩, **다중 선택 가능** (토글)
- 선택된 태그: 진한 배경(#191919) 반전
- 선택 시 하단에 소재 리스트 패널 펼침:
  - 헤더: 선택된 태그 배지 목록 + 소재 수 + "전체 해제" 버튼
  - 행: 순위 | 소재명 | 매칭 태그 배지 | 유형 | Ads 점수 | MMP 점수
  - 동작: 선택 태그 중 하나라도 보유한 소재 합산 표시
  - 재클릭 시 해제, 전체 해제 시 패널 숨김

### 5.3 피로도 탭

**기간 설정 바** (테이블 상단):
- 기준 기간: 시작일 ~ 종료일 (date input)
- 비교 기간: 시작일 ~ 종료일 (date input)
- [적용] Primary 버튼 (Red)

**피로도 테이블** (`ds-table`):
- 컬럼: 소재명 | 유형 | 기준 CPA | 비교 CPA | 변화율 | 추이(스파크라인) | 피로도 상태
- 피로도 배지: Fresh(Teal) / Stable(Blue) / Warning(Amber) / Tired(Red)
- 판정 기준은 컬럼 헤더 툴팁으로 이동

## 7. 파일 구조 및 구현 방식

현행 `step1_integrated.html` 단일 파일 구조 유지.  
변경 범위:

1. **`<head>` 폰트 로딩**: Google Fonts CDN `<link>` 태그로 Noto Sans KR(100~900) 로드. Pretendard는 기존 `fonts/` 디렉터리의 `@font-face`(`PretendardVariable.woff2`) 유지.
2. **`<style>` 블록 최상단**: `_design_system_temp/colors_and_type.css`의 `:root { }` 토큰 변수 전체를 복사 삽입. 이후 컴포넌트 CSS는 해당 변수를 참조하여 작성.
3. **`<body>` HTML 구조**: 기존 수직 섹션 → `topbar(44px) + body(sidebar 240px + main flex-1)` 레이아웃으로 재구성.
4. **JavaScript**: 기존 렌더링·계산 함수 유지. 신규 추가: `toggleSidebar()`, `switchMainTab(tab)`, `toggleAiTag(el)`, `renderTagCreativeList()`.
5. **Lucide 아이콘**: CDN(`https://unpkg.com/lucide@latest`) `<script>` 추가, 기존 이모지 대체.
