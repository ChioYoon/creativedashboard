# 미매칭 소재 매칭 — 패널 접기 + 완전 병합 파일 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 미매칭 집행 소재 패널을 기본 접기로 바꾸고, 매핑 반영을 조각 대신 완전한 병합 JSON(복사+다운로드)으로 생성한다. 매칭 로직·점수는 불변.

**Architecture:** `step1_integrated.html` 인라인. `renderUnmatchedPanel`(패널 `<details>`화) + `buildAliasConfig`(async 딥 병합) + 신규 `downloadAliasConfig`.

**Tech Stack:** 바닐라 JS(fetch/Blob). preview 서버 + `preview_eval`(캐시 우회 `?_=<ts>`).

## Global Constraints

- 매칭 로직·야간 파이프라인·점수·집계·`__unmatchedAssets` 데이터 흐름 무변경. UI(접기) + 생성물 품질만 개선.
- 딥 병합: `{...current}` 최상위 보존, 활성 타이틀 `{...prevTitle, _creative_name_aliases:{...prevAliases, ...aliases}}` — 기존 `_pipeline_*`·타 타이틀 보존.
- fetch 실패 시 `fetchOk=false` → 이 타이틀 별칭만 포함 + 경고 note(graceful).
- 적용 경로: 로컬 `js/titles_overrides.json` 교체+커밋, 또는 생성물을 Claude에게 전달.

- [ ] **Step 2: buildAliasConfig 딥 병합(async) + downloadAliasConfig 신규**

`buildAliasConfig` 함수 전체(4192-4204)를 교체:
```js
    // 선택 매핑을 현재 titles_overrides.json 에 딥 병합해 '완전한 파일' 생성 (기존 설정·타 타이틀 보존)
    async function buildAliasConfig() {
      const sels = document.querySelectorAll('#unmatchedPanel select[data-unmatched-concept]');
      const aliases = {};
      sels.forEach(s => { if (s.value) aliases[s.dataset.unmatchedConcept] = s.value; });
      const out = document.getElementById('aliasConfigOut');
      if (!Object.keys(aliases).length) { out.style.display = ''; out.textContent = '매핑 대상을 1건 이상 선택하세요.'; return; }
      const titleId = (window.DataSource && DataSource.getActiveTitleId && DataSource.getActiveTitleId()) || '<title>';
      let current = {}, fetchOk = false;
      try {
        const res = await fetch('js/titles_overrides.json', { cache: 'no-store' });
        if (res.ok) { current = await res.json(); fetchOk = true; }
      } catch (_) {}
      const merged = { ...current };
      const prevTitle = merged[titleId] || {};
      const prevAliases = prevTitle._creative_name_aliases || {};
      merged[titleId] = { ...prevTitle, _creative_name_aliases: { ...prevAliases, ...aliases } };
      const fullJson = JSON.stringify(merged, null, 2);
      window._aliasConfigJson = fullJson;
      const note = fetchOk
        ? `// js/titles_overrides.json 전체를 아래 내용으로 교체하세요 (기존 설정 모두 포함됨).\n// 또는 이 내용을 Claude에게 전달하면 로컬 파일에 반영+커밋해 드립니다.\n`
        : `// ⚠️ 현재 설정 파일을 읽지 못해 이 타이틀 별칭만 포함됩니다. 기존 파일에 병합하거나 Claude에게 전달하세요.\n`;
      out.style.display = ''; out.textContent = note + fullJson;
      if (navigator.clipboard) navigator.clipboard.writeText(fullJson).catch(() => {});
    }

    // 생성된 완전 파일을 titles_overrides.json 으로 다운로드
    function downloadAliasConfig() {
      const out = document.getElementById('aliasConfigOut');
      const json = window._aliasConfigJson;
      if (!json) { if (out) { out.style.display = ''; out.textContent = '먼저 "매핑 반영 파일 생성"을 누르세요.'; } return; }
      const blob = new Blob([json], { type: 'application/json' });
      const url = URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url; a.download = 'titles_overrides.json';
      document.body.appendChild(a); a.click(); document.body.removeChild(a);
      setTimeout(() => URL.revokeObjectURL(url), 1000);
    }
```

- [ ] **Step 3: preview 검증 — 접기·병합·다운로드·불변**

`step1_integrated.html?_=<ts>` → 미매칭 자산 있는 타이틀 분석 후 `preview_eval`. (미매칭 없으면 `window.__unmatchedAssets` 합성 주입 후 `renderUnmatchedPanel()` 호출.)
```js
(async function(){
  // 미매칭 패널 보장 (실데이터 없으면 합성)
  if (!(window.__unmatchedAssets||[]).length) {
    window.__unmatchedAssets = [{ concept:'테스트집행명', source:'ads', impressions:1000, cost:50000, asset_types:['BNR'] }];
    renderUnmatchedPanel();
  }
  var panel = document.getElementById('unmatchedPanel');
  var det = panel.querySelector('details');
  var collapsedByDefault = det && !det.hasAttribute('open');
  // select 1건 설정
  var sel = panel.querySelector('select[data-unmatched-concept]');
  var hadOptions = sel && sel.options.length > 1;
  if (sel && sel.options.length > 1) sel.value = sel.options[1].value;
  await buildAliasConfig();
  var json = window._aliasConfigJson || '';
  var parsed = null, parseOk = false;
  try { parsed = JSON.parse(json); parseOk = true; } catch(e){}
  var titleId = (window.DataSource && DataSource.getActiveTitleId && DataSource.getActiveTitleId());
  var hasAliasKey = parsed && parsed[titleId] && parsed[titleId]._creative_name_aliases && Object.keys(parsed[titleId]._creative_name_aliases).length > 0;
  var preservesPepp = parsed && parsed['pepp-us'] ? true : 'pepp-us 없음(현 파일에 따라 다름)';
  return {
    collapsedByDefault: collapsedByDefault,
    downloadDefined: typeof downloadAliasConfig === 'function',
    hadSelectOptions: hadOptions,
    jsonParseOk: parseOk,
    hasAliasKey: hasAliasKey,
    preservesPepp: preservesPepp
  };
})()
```
Expected: `collapsedByDefault:true`, `downloadDefined:true`, `jsonParseOk:true`, `hasAliasKey:true`. `preservesPepp` 는 현 titles_overrides.json 에 pepp-us 있으면 true(병합 보존 확인). `preview_console_logs`(error) → 없음. `preview_screenshot`로 접힌 패널 + 펼친 후 버튼 2개 확인.
