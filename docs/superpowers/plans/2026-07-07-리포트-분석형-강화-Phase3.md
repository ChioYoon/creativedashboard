# 리포트 분석형 강화 Phase 3 (HTML 추출 강화) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "HTML 추출"(`exportResultHTML`)을 공유 리포트 다이얼로그에 태워 기간 비교를 받고, 상단 KPI 델타 헤더 + 소재별 점수·전환 기준/비교/변화율 6컬럼을 추가한다.

**Architecture:** Phase 1의 `#reportDialog`와 `computeReportComparison`을 재사용한다. 다이얼로그를 리포트 종류(요약/HTML)로 분기(`window._reportKind` + `generateReport()` 디스패처)하고, `exportResultHTML(comparison)`를 하위호환(인자 optional)으로 확장한다. 비교 데이터는 `computeReportComparison`이 반환하는 소재별 점수 리스트(`cur`/`prev`, buildFatiguePeriodScores 결과)를 key로 매칭해 사용한다. 전부 `step1_integrated.html` 인라인 JS.

**Tech Stack:** Vanilla JS(인라인), 자기완결 HTML Blob 다운로드. 신규 의존성 없음.

## Global Constraints

- 대상 파일은 `step1_integrated.html` 단일 파일만. 다른 파일 수정 금지.
- 브랜치: `main` 직접(프로젝트 컨벤션 = SDD on main, 피처 브랜치 없음).
- 비교 산식: 변화율 = `(비교 − 기준) / 기준 × 100`, 기준=0 또는 값 없음 → `—`(spec §④·Error Handling).
- 하위호환: `exportResultHTML(comparison)`에서 `comparison` 없음/`hasPrev` false → 기존 단일 스냅샷 덤프와 100% 동일(델타 헤더·6컬럼 미출력). 요약 리포트 경로(`generateSummaryReport`)는 무변경 동작.
- 비교 지표: **종합점수 + 전환** 둘 다(각 기준/비교/변화율 = 총 6컬럼). 사용자 확정.
- 델타 방향성: 전환·노출수·평균점수는 높을수록 개선(증가=녹/감소=적), 비용은 가치판단 없이 중립(회색). spec §④·§Error Handling(CPA 등 낮을수록 개선)과 일관 — 단 이 표엔 CPA 비교 컬럼 없음.
- 커밋: 각 Task 완료 시 `main`에 커밋. push는 사용자 명시 승인 후 별도(컨트롤러 처리).
- 시크릿(.env·google_ads.yaml) 읽기/출력/커밋 금지.
- 검증: pytest는 파이썬 백엔드용(JS 무관) — 회귀 없음 확인만(114 passed 유지). 런타임 검증은 컨트롤러가 preview MCP로 수행(구현 subagent는 편집 + 정적 grep + pytest + 커밋만, preview 생략).

- [ ] **Step 3: 비교 준비 블록 + 헬퍼 삽입 (통계 블록 뒤)**

찾기(~5761, 통계 블록 끝 — 유일 컨텍스트):

교체(뒤에 삽입):
```js
      const excellent = scoredV.filter(x => x.v.grade === '최우수').length;
      const poor      = scoredV.filter(x => x.v.grade === '개선필요').length;

      /* ── Phase 3: 기간 비교(점수·전환 기준/비교/변화율 + 델타 헤더) ── */
      const hasCmp = !!(comparison && comparison.hasPrev);
      const curByKey = {}, prevByKey = {};
      if (hasCmp) {
        (comparison.cur  || []).forEach(o => { curByKey[o.key]  = o; });
        (comparison.prev || []).forEach(o => { prevByKey[o.key] = o; });
      }
      // 소재 셀용: 상승=녹/하락=적(점수·전환 모두 높을수록 개선). 기준 0/누락 → —
      const pctBadge = (cur, prev) => {
        if (cur == null || prev == null || prev === 0) return '<span style="color:#9ca3af;">—</span>';
        const p = (cur - prev) / prev * 100, up = p >= 0;
        return `<span style="color:${up ? '#15803d' : '#b91c1c'};font-weight:700;">${up ? '▲ +' : '▼ '}${Math.round(p)}%</span>`;
      };
      // 델타 헤더 배지: neutral=true(비용)는 가치판단 없이 회색
      const deltaBadge = (dd, neutral) => {
        if (!dd || dd.deltaPct == null) return '<span style="color:#9ca3af;font-size:11px;">전 기간 데이터 없음</span>';
        const up = dd.deltaAbs >= 0;
        const col = neutral ? '#666666' : (up ? '#15803d' : '#b91c1c');
        return `<span style="color:${col};font-weight:700;font-size:12px;">${up ? '▲ +' : '▼ '}${Math.round(dd.deltaPct)}%</span>`;
      };
      const dcard = (label, dd, fmtv, neutral) => `
        <div style="padding:12px 16px;border-right:1px solid #eee;">
          <div style="font-size:11px;color:#666;margin-bottom:4px;">${label}</div>
          <div style="font-size:18px;font-weight:800;">${dd ? fmtv(dd.cur) : '—'}</div>
          <div style="margin-top:3px;">${deltaBadge(dd, neutral)}</div>
        </div>`;
      const kpiDeltaHeader = hasCmp ? `
        <div style="margin:0 0 20px;border:1px solid #E5E5E5;border-radius:12px;overflow:hidden;">
          <div style="padding:10px 16px;background:#F4F2EF;border-bottom:1px solid #CCCCCC;font-weight:700;font-size:13px;">
            전 기간 대비 <span style="font-weight:500;color:#666;">(기준 기간: ${comparison.prevWin.start} ~ ${comparison.prevWin.end})</span>
          </div>
          <div style="display:grid;grid-template-columns:repeat(4,1fr);">
            ${dcard('전환', comparison.kpiDeltas.전환, v => Math.round(v).toLocaleString(), false)}
            ${dcard('비용', comparison.kpiDeltas.비용, v => '₩' + Math.round(v).toLocaleString(), true)}
            ${dcard('노출수', comparison.kpiDeltas.노출수, v => Math.round(v).toLocaleString(), false)}
            ${dcard('평균 점수', comparison.kpiDeltas.avgScore, v => Number(v).toFixed(1), false)}
          </div>
        </div>` : '';
```
