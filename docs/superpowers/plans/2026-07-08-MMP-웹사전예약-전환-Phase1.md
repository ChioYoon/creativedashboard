# MMP 웹 사전예약 전환 — Phase 1 (파이프라인 수집) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 등록 기준 타이틀(ZEUS)에서 Airbridge `web_custom_complete_registration`을 UA 캠페인만 수집해 소재별 등록수(`mmp_conversions`)로 파이프라인 산출물에 주입한다.

**Architecture:** Airbridge 소스에 타이틀별 전환 메트릭(단일 스위치: 설정 시 registration 기준 + UA 스코프 ON)을 추가하고, `CreativeMmpDaily.conversions`를 파싱·집계해 `CreativeRecord.mmp_conversions`로 주입. 스코어링/프런트는 Phase 2/3.

**Tech Stack:** Python 3, Pydantic, pytest. 기존 파이프라인(`pipeline/sources/airbridge.py`, `schemas.py`, `mmp_metrics.py`, `main.py`).

## Global Constraints

- 전환 메트릭 = `web_custom_complete_registration`(이벤트수). ZEUS만 활성, 앱 타이틀은 기존 `installs` 무변경.
- **단일 스위치**: 타이틀 `_pipeline_airbridge_conversion_metric` 설정 유무가 registration 기준 + UA 스코프를 함께 결정. 별도 플래그 없음.
- **UA 스코프**: registration 기준 활성 시 `campaign_ua_type(campaign) == ''`(非UA=BR·검색)인 Airbridge 행은 전량 스킵 → 전환·노출·비용 모두 UA 캠페인만 집계. 기준: 기존 `pipeline/campaign_canonical.py`의 `campaign_ua_type()` / `_KNOWN_UA_TYPES=("NU-Pre","RT","Boosting","NU")` **재사용**(새 목록 금지).
- 소재명 매칭은 신규 없음 — 기존 `resolve_concept()` 조인 그대로.
- 하위호환: conversion_metric 미설정 → 기존 동작 100% 동일(설치 4지표).
- 시크릿(.env·google_ads.yaml) 읽기/출력/커밋 금지. 토큰 값 로그 금지.
- 브랜치: `main` 직접(프로젝트 컨벤션 = SDD on main). 커밋은 각 Task, push는 사용자 승인 후.
- 테스트: `pytest -q` 전체 통과(신규 포함). 실행 = `PYTHONUTF8=1 PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -m pytest`.

```python
def parse_actuals_rows(result: dict, metrics_map: dict, exclude_channels: set,
                       default_date: str = "", fx_rate: float = 1.0,
                       ua_scope: bool = False) -> list[CreativeMmpDaily]:
    rows = (((result.get("actuals") or {}).get("data") or {}).get("rows")) or []
    out: list[CreativeMmpDaily] = []
    for row in rows:
        gb = row.get("groupBys") or []
        if len(gb) < 2:
            continue
        creative, channel = gb[0], gb[1]
        campaign_name = gb[2] if len(gb) > 2 else ""
        dt = gb[3] if len(gb) > 3 else default_date
        if not creative or channel in exclude_channels:
            continue
        if ua_scope and campaign_ua_type(campaign_name) == "":
            continue                      # 등록 기준: 非UA(BR·검색) 캠페인 행 전량 제외
        vals = row.get("values") or {}

        def gv(field: str) -> float:
            key = metrics_map.get(field) or ""
            if not key:
                return 0.0
            cell = vals.get(key) or {}
            return float(cell.get("value", 0) or 0)

        out.append(CreativeMmpDaily(
            creative_name=creative, date=dt, channel=channel, campaign_name=campaign_name,
            impressions=int(round(gv("impressions"))),
            clicks=int(round(gv("clicks"))),
            cost=int(round(gv("cost") * fx_rate)),
            installs=int(round(gv("installs"))),
            retained_d1=int(round(gv("retained_d1"))),
            revenue_d7=int(round(gv("revenue_d7") * fx_rate)),
            conversions=int(round(gv("conversions"))),
        ))
    return out
```
