# Batch D — ⑨ 소재 라이브/제외 상태 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 소재별 라이브/제외 상태를 자동 판정(최근 노출) + 개인 수동 오버라이드(localStorage)로 기록·표시하되, 분석·점수·집계는 전혀 바꾸지 않는다.

**Architecture:** `step1_integrated.html` 인라인. 상태 헬퍼(파생·저장·배지) + 표 소재명 셀 배지(display) + 모달 세그먼트 컨트롤(write). 상태는 표시 전용.

**Tech Stack:** 바닐라 JS. preview 서버 + `preview_eval`(캐시 우회 `?_=<ts>`, 함수 단위 단언).

## Global Constraints

- **분석·점수·등급·군집·요약·집계 무변경.** 상태값/배지는 어떤 집계 입력에도 들어가지 않음. '제외' 표식 소재도 모든 계산에 포함.
- 자동 판정 기준: 데이터 창 최신일 기준 최근 `LIVE_LOOKBACK_DAYS = 2`일 내 `kpi_daily.impressions > 0` → 라이브, 아니면 중단.
- 오버라이드 저장: `localStorage['r_team_status_' + titleId] = { [소재key]: 'live'|'excluded' }`. 오버라이드만 저장(자동은 미저장). 소재 key = `c.key`(=소재명).
- 자동 판정은 Google Ads 노출 기준 — 레이어 토글(ads/mmp) 무관 동일 표기.
- titleId: `DataSource.getActiveTitleId()`. 전역 표 데이터: `window.currentCreatives`. 렌더 함수: `renderResultTableRows(creatives)`.

```js
    // ⑨ 소재 라이브/제외 상태 (자동 판정 + 개인 수동 오버라이드). 표시 전용 — 분석·집계 무관.
    const LIVE_LOOKBACK_DAYS = 2;
    const STATUS_STORE_PREFIX = 'r_team_status_';
    function statusStoreKey() {
      const tid = (window.DataSource && DataSource.getActiveTitleId && DataSource.getActiveTitleId()) || '_';
      return STATUS_STORE_PREFIX + tid;
    }
    function loadStatusOverrides() {
      try { return JSON.parse(localStorage.getItem(statusStoreKey()) || '{}') || {}; }
      catch (_) { return {}; }
    }
    function saveStatusOverride(creativeKey, value /* 'live' | 'excluded' | null */) {
      const m = loadStatusOverrides();
      if (value === null) delete m[creativeKey]; else m[creativeKey] = value;
      try { localStorage.setItem(statusStoreKey(), JSON.stringify(m)); } catch (_) {}
    }
    function computeGlobalMaxDate(creatives) {
      let max = null;
      (creatives || []).forEach(c => {
        const daily = (c.meta && c.meta.kpi_daily) || [];
        daily.forEach(d => { const s = String(d.date || ''); if (s && (max === null || s > max)) max = s; });
      });
      return max;
    }
    function deriveAutoStatus(creative, globalMaxDate) {
      if (!globalMaxDate) return 'stopped';
      const daily = (creative.meta && creative.meta.kpi_daily) || [];
      const maxMs = new Date(globalMaxDate).getTime();
      const recent = daily.some(d => {
        if (Number(d.impressions || 0) <= 0) return false;
        const diff = (maxMs - new Date(String(d.date)).getTime()) / 86400000;
        return diff >= 0 && diff <= LIVE_LOOKBACK_DAYS;
      });
      return recent ? 'live' : 'stopped';
    }
    function resolveStatus(creative, globalMaxDate, overrides) {
      const ov = overrides[creative.key];
      if (ov === 'live' || ov === 'excluded') return ov;
      return deriveAutoStatus(creative, globalMaxDate);
    }
    function statusBadgeHtml(status) {
      const map = {
        live:     { dot: '#22c55e', label: '라이브' },
        stopped:  { dot: '#9ca3af', label: '중단(최근 노출 없음)' },
        excluded: { dot: '#ef4444', label: '제외(수동)' },
      };
      const s = map[status] || map.stopped;
      const mark = status === 'excluded'
        ? '🚫'
        : `<span style="display:inline-block;width:8px;height:8px;border-radius:50%;background:${s.dot};"></span>`;
      return `<span class="status-badge" title="${s.label}" style="display:inline-flex;align-items:center;flex:none;">${mark}</span>`;
    }
```

```js
    // ⑨ 모달 라이브 상태 세그먼트 컨트롤 (자동/라이브/제외) — 저장 후 표 배지 즉시 갱신
    function wireStatusButtons(creative) {
      const wrap = document.getElementById('modalStatusControl');
      if (!wrap) return;
      const btns = wrap.querySelectorAll('.status-seg-btn');
      const cur = () => { const ov = loadStatusOverrides()[creative.key]; return (ov === 'live' || ov === 'excluded') ? ov : 'auto'; };
      const paint = () => { const c = cur(); btns.forEach(b => { const on = b.dataset.status === c; b.style.background = on ? '#E84855' : '#fff'; b.style.color = on ? '#fff' : '#374151'; b.style.fontWeight = on ? '700' : '500'; }); };
      btns.forEach(b => b.addEventListener('click', () => {
        const v = b.dataset.status;
        saveStatusOverride(creative.key, v === 'auto' ? null : v);
        paint();
        if (typeof renderResultTableRows === 'function' && window.currentCreatives) renderResultTableRows(window.currentCreatives);
      }));
      paint();
    }
```
