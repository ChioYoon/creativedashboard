# 소재명 별칭 매핑 + 미매칭 리포트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Google Ads/MMP 광고 자산명이 GDrive 소재명과 다를 때 수동 별칭 맵으로 조인하고, 미매칭(집행O·미조인) 소재를 step1 대시보드에 노출해 매핑하게 한다.

**Architecture:** 파이프라인이 `titles_overrides.json`의 `_creative_name_aliases`를 직접 읽어 KPI·MMP 조인에서 `resolve_concept ∉ candidate`일 때 별칭으로 귀속. 미매칭 자산을 `CreativeDataset.unmatched_assets`로 출력 → step1이 패널+드롭다운 매핑 UI로 표시·config 스니펫 생성(단일 진실원=config).

**Tech Stack:** Python 3 / pydantic (파이프라인), 정적 HTML+바닐라 JS (대시보드), pytest, preview.

## Global Constraints

- 별칭 키 = `resolve_concept` 출력(미매칭 concept). 사이즈 변형(L/S/V)이 한 concept 공유 → 별칭 1건이 전 변형 커버.
- `resolve_concept`(순수 파싱) 불변 — 별칭은 **조인 단계에서만** 조회. 기존 조인 산식·동작 변경 금지(별칭 재매핑+미매칭 수집만 추가).
- 단일 진실원 = `titles_overrides.json`(main.py가 **직접** 읽음 — registry 활성 여부 무관). 대시보드는 표시·매핑입력·config생성만(직접 저장 X).
- 미매칭 필터: Google Ads = `impressions>0` + `asset_type ∈ {IMAGE, YOUTUBE_VIDEO}`(TEXT·MEDIA_BUNDLE 제외). MMP = `installs>0 or impressions>0`(MMP 행엔 asset_type 없음 → `asset_types: []`).
- 미매칭 항목 = `{"concept": str, "source": "google_ads"|"mmp", "impressions": int, "cost": float, "asset_types": list[str]}`, impressions 내림차순.
- 하위호환: 별칭 맵/`unmatched_assets` 부재 시 현행 동작(무크래시). 대시보드는 필드 부재·0건 시 패널 숨김.
- `.env`/`.secrets` 절대 읽기·출력 금지. 본 작업 API 호출 0(설정·조인 로직만).

def apply_alias(concept: str, candidates, aliases) -> str:
    """concept 가 candidates 에 있으면 그대로, 없으면 별칭 맵으로 재매핑(없으면 자기 자신)."""
    if concept in candidates:
        return concept
    return (aliases or {}).get(concept, concept)


def _load_creative_aliases(title: str, repo_root: Path) -> dict:
    """js/titles_overrides.json 에서 {title}._creative_name_aliases 직접 로드(dict).
       registry(CLOOP_REGISTRY_XLSX) 활성 여부와 무관하게 동작. 파일/키 부재 → {}."""
    if not title:
        return {}
    path = repo_root / "js" / "titles_overrides.json"
    if not path.exists():
        return {}
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
        al = (data.get(title) or {}).get("_creative_name_aliases") or {}
        return al if isinstance(al, dict) else {}
    except Exception as e:
        print(f"   [경고] titles_overrides.json 별칭 로드 실패(무시): {e}")
        return {}
```

_UNMATCHED_GA_TYPES = ("IMAGE", "YOUTUBE_VIDEO")


def build_kpi_index(kpi_rows, candidate_concepts, aliases=None):
    """Google Ads KPI 행 → (concept→rows 인덱스, 미매칭 자산 리스트).

    조인: resolve_concept → 별칭(apply_alias) → candidate 매칭.
    미매칭: 매칭 실패 + impressions>0 + asset_type ∈ IMAGE/YOUTUBE_VIDEO (원본 concept 키로 집계).
    """
    index: dict = {}
    unmatched: dict = {}  # raw concept -> {impr, cost, types}
    for row in kpi_rows:
        raw = resolve_concept(row.creative_name)
        concept = apply_alias(raw, candidate_concepts, aliases)
        if concept in candidate_concepts:
            index.setdefault(concept, []).append(row)
        else:
            at = getattr(row, "asset_type", "") or ""
            if (getattr(row, "impressions", 0) or 0) > 0 and at in _UNMATCHED_GA_TYPES:
                e = unmatched.setdefault(raw, {"impr": 0, "cost": 0.0, "types": set()})
                e["impr"] += row.impressions or 0
                e["cost"] += getattr(row, "cost", 0) or 0
                e["types"].add(at)
    unmatched_list = [
        {"concept": c, "source": "google_ads", "impressions": v["impr"],
         "cost": round(v["cost"], 2), "asset_types": sorted(v["types"])}
        for c, v in sorted(unmatched.items(), key=lambda x: -x[1]["impr"])
    ]
    return index, unmatched_list
```

    """CreativeMmpDaily 리스트를 소재명(concept)으로 join 하여 records 에 mmp_* 주입.

    소재명 매칭: ad_creative == 파일명/소재명 컨벤션. 별칭(aliases)로 비표준명 재매핑.

        return []

    function renderUnmatchedPanel() {
      const panel = document.getElementById('unmatchedPanel');
