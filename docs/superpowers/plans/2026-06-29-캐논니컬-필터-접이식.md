# 캐논니컬 필터 접이식 그룹 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** step1 캐논니컬 캠페인 유형 필터의 각 차원을 접이식 아코디언으로 바꿔 사이드바 높이를 차원·값 수와 무관하게 고정한다.

**Architecture:** `populateCanonicalFilter()`가 차원별로 클릭 헤더(라벨+선택수 배지+chevron) + 접힌 콘텐츠(내부 스크롤)를 렌더. 신규 `toggleCanonGroup(key)`가 펼침/접힘. `onCanonicalChange()`가 선택수 배지를 갱신. 전부 `step1_integrated.html` 인라인. 필터 판정 로직은 무변경.

**Tech Stack:** 바닐라 JS(브라우저 인라인), 인라인 스타일. `step1_integrated.html`. JS 테스트 러너 없음 → preview 서버 + `preview_eval`.

## Global Constraints

- **표시 방식만 변경** — 필터 판정(`resolveCanonicalCampaigns`/`resolveCanonicalAllowed`/`refreshCampaignVisibility`), 캠페인 검색, 데이터 로직 무변경.
- **기본 전부 접힘** — 콘텐츠 `display:none` 으로 시작(선택 차원 자동 펼침 없음, 선택은 배지로 표시).
- **값 많은 차원 내부 스크롤** — 콘텐츠 `max-height:120px; overflow-y:auto`.
- **기존 인라인 스타일 컨벤션 유지** — 신규 CSS 파일/클래스 없음.
- ID 규칙: `canonGroup_${key}` (콘텐츠), `canonChevron_${key}` (▸/▾), `canonCount_${key}` (배지).
- 검증은 preview 서버(`cloop-static`, 8765). 인라인 함수 변경이므로 캐시 우회용 쿼리(`?_=<ts>`)로 새 문서 로드 후 검증.

### Task 1: 접이식 캐논니컬 필터

**Files:**
- Modify: `step1_integrated.html` — `populateCanonicalFilter`(약 4199~4205행), `onCanonicalChange`(약 4209~4215행), 전체-해제 블록(약 4203~4207행에 신설 `toggleCanonGroup` + 6103~6107행 배지 리셋).

**Interfaces:**
- Consumes: `CANON_DIMS`(`[{key,label}]`), `currentCanonical`(`{key: Set}`), `window.__campaignCanonical`, `refreshCampaignVisibility()` — 모두 기존.
- Produces: `toggleCanonGroup(key: string)` — 그룹 콘텐츠 display 토글.

- [ ] **Step 1: `populateCanonicalFilter` 렌더를 아코디언으로 교체**

`step1_integrated.html` 의 `host.innerHTML = CANON_DIMS.map(d => { ... }).join('');` 블록(현재 4199~4204행)을 아래로 교체:

```js
      host.innerHTML = CANON_DIMS.map(d => {
        const opts = [...values[d.key]].sort().map(v =>
          `<label style="display:inline-flex;align-items:center;gap:3px;font-size:11px;margin:0 6px 4px 0;cursor:pointer;">` +
          `<input type="checkbox" data-canon="${d.key}" value="${v}" onchange="onCanonicalChange()" style="margin:0;">${v}</label>`).join('');
        return `<div style="margin-bottom:4px;border-bottom:1px solid #f1f1f1;">
          <div onclick="toggleCanonGroup('${d.key}')" style="display:flex;align-items:center;justify-content:space-between;cursor:pointer;padding:5px 0;">
            <span style="font-size:11px;font-weight:700;color:#6b7280;">${d.label}</span>
            <span style="display:flex;align-items:center;gap:5px;">
              <span id="canonCount_${d.key}" style="display:none;font-size:10px;background:#eef2ff;color:#4f46e5;border-radius:5px;padding:0 6px;line-height:1.6;"></span>
              <span id="canonChevron_${d.key}" style="font-size:10px;color:#9ca3af;">▸</span>
            </span>
          </div>
          <div id="canonGroup_${d.key}" style="display:none;max-height:120px;overflow-y:auto;padding:2px 0 5px;">${opts}</div>
        </div>`;
      }).join('');
```

- [ ] **Step 2: 신규 `toggleCanonGroup(key)` 추가**

`populateCanonicalFilter` 함수 닫는 `}` 바로 다음(현재 4206행 아래, `onCanonicalChange` 정의 앞)에 추가:

```js
    // 캐노니컬 그룹 접기/펼치기 토글 (표시만 — 상태는 DOM display 에서 직접 읽음)
    function toggleCanonGroup(key) {
      const c = document.getElementById('canonGroup_' + key);
      const ch = document.getElementById('canonChevron_' + key);
      if (!c) return;
      const open = c.style.display !== 'none';
      c.style.display = open ? 'none' : '';
      if (ch) ch.textContent = open ? '▸' : '▾';
    }
```

- [ ] **Step 3: `onCanonicalChange` 에 선택수 배지 갱신 추가**

`onCanonicalChange` 함수 안 `refreshCampaignVisibility();` 호출 바로 앞(또는 뒤)에 배지 갱신 루프 추가:

```js
    function onCanonicalChange() {
      CANON_DIMS.forEach(d => currentCanonical[d.key] = new Set());
      document.querySelectorAll('#canonicalFilterGroups input[type="checkbox"]:checked').forEach(cb => {
        currentCanonical[cb.dataset.canon].add(cb.value);
      });
      CANON_DIMS.forEach(d => {
        const badge = document.getElementById('canonCount_' + d.key);
        if (!badge) return;
        const n = currentCanonical[d.key].size;
        badge.textContent = String(n);
        badge.style.display = n > 0 ? '' : 'none';
      });
      refreshCampaignVisibility();
    }
```

- [ ] **Step 4: 전체-해제 시 배지 리셋**

전체-해제 블록(현재 6106행 `document.querySelectorAll('#canonicalFilterGroups input[type="checkbox"]').forEach(cb => cb.checked = false);` 직후)에 배지 숨김 추가 — 프로그램적 uncheck 는 onchange 를 발화하지 않으므로:

```js
        document.querySelectorAll('#canonicalFilterGroups input[type="checkbox"]').forEach(cb => cb.checked = false);
        CANON_DIMS.forEach(d => { const b = document.getElementById('canonCount_' + d.key); if (b) b.style.display = 'none'; });
```
