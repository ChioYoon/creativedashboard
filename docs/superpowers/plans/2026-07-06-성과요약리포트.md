# 성과 요약 리포트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 결과 툴바의 "요약 리포트" 버튼으로, 분석 결과를 큐레이션한 1장 요약(핵심 KPI·Top5 소재·유형 요약·인사이트)을 자체 완결 HTML(인쇄용)로 원클릭 생성한다.

**Architecture:** 데이터 조립(`buildSummaryReportData`)과 HTML 렌더(`renderSummaryReportHtml`)를 분리해 각각 테스트 가능하게 하고, `exportSummaryReport`가 이 둘을 엮어 Blob 다운로드한다. `window.currentCreatives`와 기존 집계 함수(`creativeLayerView`·`aggregateTypeMetrics`/`typeBlended`·`detectConversionBasis`)를 재사용한다. 전부 `step1_integrated.html` 내 인라인 JS.

**Tech Stack:** 정적 HTML/CSS/바닐라 JS 단일 파일. 빌드 없음. 검증 = preview MCP(브라우저 eval).

**Spec:** docs/superpowers/specs/2026-07-06-성과요약리포트-design.md

## Global Constraints

- 진입점 = 결과 툴바 `#resultToolbar .rt-right`에 "요약 리포트" 버튼(기존 HTML 추출 버튼 앞) → `exportSummaryReport()`.
- 리포트 5섹션: ① 헤더(타이틀·기간·레이어·생성일) ② KPI 5카드(소재 수·평균 점수·최우수·개선필요·총 전환) ③ Top5 소재(썸네일·이름·전환·CPA·점수·등급) ④ 유형별 요약(소재 수·평균 점수) ⑤ AI 인사이트(있으면).
- 데이터: `currentCreatives` + `creativeLayerView(c)`(레이어 인지 지표) + `aggregateTypeMetrics`/`typeBlended`(유형) + `detectConversionBasis`(전환 라벨) + `#titleSelector`(타이틀명) + `#startDate`/`#endDate`(기간) + `window.currentAnalysisLayer`(레이어) + `#scoringAIBox`(인사이트). 신규 계산 최소화.
- 출력 = 자체 완결 HTML(인라인 `<style>` + `@media print` + 내장 "인쇄/PDF 저장" 버튼) → Blob 다운로드(`exportResultHTML` 패턴). 파일명 `성과요약_<타이틀>_<YYYYMMDD_HHMM>.html`.
- 가드: `currentCreatives` 없음/빈 배열 → `alert('분석 결과가 없습니다. 점수 계산을 먼저 실행해 주세요.')` 후 return.
- 인사이트 미생성(`#scoringAIBox` 비어있음) → 인사이트 섹션 생략.
- 단일 파일 `step1_integrated.html` 인라인 JS/HTML. 프로젝트 컨벤션 = main 브랜치 SDD.
- JS 단위 테스트 프레임워크 없음 → 검증은 preview MCP: zeus 로드 → `calculateScores()` → 함수 eval로 반환/문자열 확인.

- [ ] **Step 1: `buildSummaryReportData` 함수 추가**

`step1_integrated.html`에서 `function exportResultHTML() {` 정의(약 5343행)를 찾아, 그 **바로 앞 줄**에 아래 함수를 삽입한다:

```js
    // ── 성과 요약 리포트: 데이터 조립 (currentCreatives + 기존 집계 재사용) ──
    function buildSummaryReportData(creatives) {
      const cs = creatives || [];
      const sel = document.getElementById('titleSelector');
      const titleName = (sel && sel.selectedOptions && sel.selectedOptions[0])
        ? sel.selectedOptions[0].textContent.trim()
        : ((sel && sel.value) || '소재분석');
      const _s = document.getElementById('startDate'), _e = document.getElementById('endDate');
      const period = (_s && _e && _s.value && _e.value) ? `${_s.value} ~ ${_e.value}` : '전체 기간';
      const layer = (window.currentAnalysisLayer === 'mmp') ? 'MMP 기준' : 'Google Ads 기준';
      const convBasis = (typeof detectConversionBasis === 'function') ? detectConversionBasis() : '설치';

      const views = cs.map(c => ({ c, v: creativeLayerView(c) }));
      const withData = views.filter(x => x.v.hasData);
      const scores = withData.map(x => x.v.score).filter(s => s != null);
      const kpis = {
        count: cs.length,
        avgScore: scores.length ? (scores.reduce((s, v) => s + v, 0) / scores.length) : null,
        excellent: withData.filter(x => x.v.grade === '최우수').length,
        poor: withData.filter(x => x.v.grade === '개선필요').length,
        totalConv: withData.reduce((s, x) => s + (Number(x.v.전환) || 0), 0),
        convBasis,
      };

      const topN = withData.slice()
        .sort((a, b) => (b.v.score || 0) - (a.v.score || 0))
        .slice(0, 5)
        .map(x => ({
          thumb: x.c.이미지링크 || '', type: x.c.유형 || '',
          name: x.c.key || '', conv: x.v.전환, cpa: x.v.CPA, score: x.v.score, grade: x.v.grade || '',
        }));

      const types = (typeof aggregateTypeMetrics === 'function') ? aggregateTypeMetrics(cs) : {};
      const typeRows = Object.keys(types).map(t => ({
        type: t, count: types[t].count, avgScore: typeBlended(types[t]).avg,
      })).sort((a, b) => b.count - a.count);

      const box = document.getElementById('scoringAIBox');
      const insightHtml = (box && box.textContent.trim()) ? box.innerHTML : '';

      return { titleName, period, layer, kpis, topN, typeRows, insightHtml };
    }
```

    // ── 성과 요약 리포트: HTML 렌더 (자체 완결·인쇄용) ──
    function renderSummaryReportHtml(data) {
      const esc = s => String(s == null ? '' : s).replace(/[&<>"]/g, m => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[m]));
      const won = v => (v != null) ? '₩' + Math.round(v).toLocaleString() : '—';
      const num = v => (v != null) ? Math.round(v).toLocaleString() : '—';
      const sc  = v => (v != null) ? Number(v).toFixed(1) : '—';
      const now = new Date();
      const p2 = n => String(n).padStart(2, '0');
      const gen = `${now.getFullYear()}-${p2(now.getMonth()+1)}-${p2(now.getDate())} ${p2(now.getHours())}:${p2(now.getMinutes())}`;
      const gradeStyle = {

        '개선필요': 'background:#fee2e2;color:#b91c1c;'
      };
      const k = data.kpis;
      const kpiCard = (label, val, color) =>
        `<div class="kc"><div class="kl">${esc(label)}</div><div class="kv"${color ? ` style="color:${color};"` : ''}>${val}</div></div>`;
      const kpiHtml = [
        kpiCard('소재 수', num(k.count)),
        kpiCard('평균 점수', sc(k.avgScore)),
        kpiCard('최우수', num(k.excellent), '#15803d'),
        kpiCard('개선필요', num(k.poor), '#6b7280'),
        kpiCard(`총 전환(${esc(k.convBasis)})`, num(k.totalConv)),
      ].join('');
      const topHtml = data.topN.length ? data.topN.map(t => `
        <div class="tr">
          <div class="tt">${t.thumb ? `<img src="${esc(t.thumb)}" alt="">` : esc(t.type)}</div>
          <div class="tn"><div class="tnm">${esc(t.name)}</div><div class="tms">전환 ${num(t.conv)} · CPA ${won(t.cpa)} · 점수 ${sc(t.score)}</div></div>
          <span class="gb" style="${gradeStyle[t.grade] || gradeStyle['보통']}">${esc(t.grade || '—')}</span>
        </div>`).join('') : '<div class="empty">표시할 소재가 없습니다.</div>';
      const typeHtml = data.typeRows.map(r =>
        `<tr><td>${esc(r.type)}</td><td class="r">${num(r.count)}</td><td class="r">${sc(r.avgScore)}</td></tr>`).join('');
      const insightBlock = data.insightHtml
        ? `<div class="sec"><div class="st">인사이트</div><div class="ins">${data.insightHtml}</div></div>` : '';

      return `<!DOCTYPE html><html lang="ko"><head><meta charset="UTF-8">

<style>

    // ── 성과 요약 리포트: 생성·다운로드 ──
    function exportSummaryReport() {
      const creatives = window.currentCreatives;
      if (!creatives || creatives.length === 0) {
        alert('분석 결과가 없습니다. 점수 계산을 먼저 실행해 주세요.');
        return;
      }
      const data = buildSummaryReportData(creatives);
      const html = renderSummaryReportHtml(data);
      const now = new Date();
      const p2 = n => String(n).padStart(2, '0');
      const stamp = `${now.getFullYear()}${p2(now.getMonth()+1)}${p2(now.getDate())}_${p2(now.getHours())}${p2(now.getMinutes())}`;
      const safeTitle = String(data.titleName).replace(/[\\/:*?"<>|\s]+/g, '').slice(0, 30) || '소재분석';
      const fileName = `성과요약_${safeTitle}_${stamp}.html`;
      const blob = new Blob([html], { type: 'text/html;charset=utf-8' });
      const url = URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url; a.download = fileName;
      document.body.appendChild(a); a.click();
      setTimeout(() => { URL.revokeObjectURL(url); a.remove(); }, 1000);
      console.log('요약 리포트 생성: ' + fileName);
    }
