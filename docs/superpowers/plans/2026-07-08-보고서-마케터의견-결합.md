# 보고서 마케터 의견 결합 (1a) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 보고서 생성 다이얼로그에서 마케터 의견을 입력하면 AI가 개조식으로 정리하고 데이터로 검증(뒷받침/반박/확인불가)해 보고서 전용 섹션으로 결합한다.

**Architecture:** step1_integrated.html 인라인 JS만 수정. 마케터 노트는 `generateSummaryReport` → `buildReportNarrative(note)` → `buildReportNarrativePrompt(note)` 경로로 Gemini 프롬프트에 주입되고, 생성된 내러티브(마케터 2섹션 + 기존 4섹션)는 기존 렌더 경로(`exportSummaryReport`→`buildSummaryReportData`→보고서 HTML의 "AI 코멘트" 섹션, `■` 헤더 볼드)를 그대로 통과한다. 무키/실패 시 원문을 개조식 섹션으로 폴백 렌더.

**Tech Stack:** 순수 HTML/JS(인라인), Gemini API(`callGeminiAPI`), localStorage.

## Global Constraints

- **검증형 결합(verbatim):** AI는 마케터 의견을 *가설*로 받아 데이터로 검증. 무비판적 동조 금지. "마케터 관점"과 "데이터 근거" 구분. 데이터로 확인 안 되면 "데이터로 확인 불가"로 명시.
- **출력 형식(기존 프롬프트 규칙 유지):** 개조식 음슴체, 섹션 제목 `■ `, 불릿 ` - `, 마크다운(`**`,`##`)·서론·맺음말 금지.
- **섹션 순서:** `■ 마케터 관점` → `■ 마케터 관점 검증` → 기존 4섹션(`■ 핵심 변화` / `■ 우수 요소 (저효율 대비)` / `■ 성과 좋은 소재군` / `■ 부진 요인·다음 액션`).
- **선택 입력·무회귀:** 노트가 비면 마케터 섹션 미출력·프롬프트 불변 → 현재 보고서와 동일.
- **저장 범위:** 타이틀별 localStorage(그 브라우저·개인 편의만, 팀 공유 아님). 팀 공유·영속·태깅 반영은 후속 1b.
- **무키/실패 폴백:** Gemini 키 미설정 또는 호출 실패로 내러티브가 없고 노트가 있으면 원문을 `■ 마케터 관점` 개조식으로만 표시(정리·검증 생략).
- **파이프라인·데이터·공용 JS(layer-metrics.js) 변경 없음 → 캐시버스터 범프 불필요**(step1 인라인만 변경, 하드 새로고침 반영).
- **검증 방식:** 프런트 JS 자동 테스트 하네스 없음. "테스트"=preview 런타임 검증(콘솔 무에러 + 동작 확인). pytest·node --check(인라인 HTML 불가) 대상 아님.

```javascript
    async function generateSummaryReport() {
      const s = document.getElementById('startDate')?.value, e = document.getElementById('endDate')?.value;
      const ps = document.getElementById('reportPrevStart').value, pe = document.getElementById('reportPrevEnd').value;
      const note = (document.getElementById('reportMarketerNote')?.value || '').trim();
      try { if (note) localStorage.setItem(reportNoteKey(), note); else localStorage.removeItem(reportNoteKey()); } catch (_) {}
      const layer = window.currentAnalysisLayer || 'ads';
      const curWin = { start: s, end: e };
      const prevWin = (ps && pe) ? { start: ps, end: pe } : null;
      const cmp = computeReportComparison(window.currentCreatives, curWin, prevWin, layer, getReportWeights());
      closeReportDialog();
      let narrative = '';
      if (typeof GeminiKeyManager !== 'undefined' && GeminiKeyManager.isSet()) {
        showLoadingIndicator('AI 코멘트 생성 중...');
        try { narrative = await buildReportNarrative(cmp, window.currentCreatives, note); }
        finally { hideLoadingIndicator(); }
      }
      // 무키/실패 폴백: 내러티브 없고 노트 있으면 원문을 개조식 섹션으로만 표시(정리·검증 생략)
      if (!narrative && note) {
        narrative = '■ 마케터 관점\n' + note.split('\n').map(ln => ln.trim()).filter(Boolean).map(ln => ' - ' + ln).join('\n');
      }
      exportSummaryReport(cmp, narrative);
    }
```

- [ ] **Step 1: `buildReportNarrative`에 note 인자 추가**

기존 함수(5539-5550)를 아래로 교체(변경점: 시그니처 `note=''`, 프롬프트에 note 전달, note 있을 때 maxTokens 상향):

```javascript
    async function buildReportNarrative(comparison, creatives, note = '') {
      if (typeof GeminiKeyManager === 'undefined' || !GeminiKeyManager.isSet()) return '';
      try {
        const data = buildSummaryReportData(creatives, comparison);
        const tags = buildTagCohortSummary(comparison && comparison.cur, creatives);
        const prompt = buildReportNarrativePrompt(data, tags, note);
        return await callGeminiAPI(prompt, { maxTokens: note ? 1100 : 800, temperature: 0.6 });
      } catch (e) {
        console.warn('AI 코멘트 생성 실패:', e && e.message);
        return '';
      }
    }
```
