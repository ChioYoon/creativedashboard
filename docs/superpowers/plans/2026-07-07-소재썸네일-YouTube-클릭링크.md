# 소재 썸네일 YouTube 대응 + 클릭 링크 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 세 HTML 추출물(요약 리포트·HTML 추출·제작 브리프)에서 영상(VID) 소재의 미리보기가 안 나오는 버그를 고치고, 이미지·영상 소재 모두 클릭 시 원본을 여는 링크를 추가한다.

**Architecture:** 근본 원인은 `이미지링크`(영상은 `youtube.com/watch?v=…` 웹페이지 URL)를 그대로 `<img src>`에 넣어 깨지는 것. 공용 헬퍼 `creativeThumbHtml(url, type, w, h)` 하나를 만들어 ① YouTube URL→`img.youtube.com/vi/{id}/hqdefault.jpg` 썸네일 변환, ② 이미지 URL→원본, ③ 둘 다 `<a target="_blank">` 클릭 링크, ④ 로드 실패 시 아이콘 폴백(뒤에 깔린 라벨을 `onerror`로 노출)을 자기완결 인라인 스타일로 반환. 네 개 렌더 사이트가 이 헬퍼를 호출하도록 교체. 전부 `step1_integrated.html` 인라인 JS.

**Tech Stack:** Vanilla JS(인라인), 자기완결 HTML Blob 다운로드. 신규 의존성 없음.

## Global Constraints

- 대상 파일은 `step1_integrated.html` 단일 파일만. 다른 파일 수정 금지.
- 브랜치: `main` 직접(프로젝트 컨벤션 = SDD on main).
- 헬퍼는 **한 번만 정의**(DRY). 네 사이트는 이 헬퍼를 호출만 함(로직 중복 금지).
- 영상 썸네일 = `https://img.youtube.com/vi/{VIDEO_ID}/hqdefault.jpg`. VIDEO_ID는 `watch?v=`, `youtu.be/`, `embed/`, `shorts/` 형태에서 추출(11자).
- 이미지·영상 **모두 클릭 시 새 탭**(`<a target="_blank" rel="noopener">`)으로 원본(영상=watch URL, 이미지=원본 URL) 열기.
- 로드 실패/URL 없음 → 아이콘(유형 라벨 'VID'/'IMG') 폴백. URL이 아예 없으면 링크 없는 아이콘 박스.
- XSS: 헬퍼 내 URL·라벨은 `esc()` 처리 후 삽입. `onerror`는 HTML 문자열 재조립 없이 `this.style.display='none'`만(따옴표 이스케이프 이슈 회피).
- 시크릿(.env·google_ads.yaml) 읽기/출력/커밋 금지.
- 검증: pytest는 파이썬 백엔드용(JS 무관) — 114 passed 유지 확인. 런타임 검증은 컨트롤러가 preview MCP로 수행(구현 subagent는 편집+정적grep+pytest+커밋만, preview 생략).
- 커밋: 각 Task 완료 시 `main`에 커밋. push는 사용자 명시 승인 후 별도(컨트롤러).

```js
    // ── 소재 썸네일 셀(공용): 영상=YouTube 썸네일, 이미지=원본, 둘 다 클릭 링크(새 탭), 로드 실패 시 아이콘 폴백 ──
    function creativeThumbHtml(url, type, w, h) {
      const esc = s => String(s == null ? '' : s).replace(/[&<>"]/g, ch => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[ch]));
      const u = String(url || '');
      const t = String(type || '').toUpperCase();
      const isVid = t === 'VID';
      const ym = u.match(/(?:youtube\.com\/(?:watch\?v=|embed\/|shorts\/)|youtu\.be\/)([\w-]{11})/);
      const yid = ym ? ym[1] : '';
      const isImg = /^https?:\/\//.test(u) && !yid;
      const box = `width:${w}px;height:${h}px;border-radius:6px;flex:none;`;
      const label = esc(t || (isVid ? 'VID' : 'IMG')) || '—';
      const fs = Math.max(9, Math.round(h / 4.5));
      const iconBox = `<div style="${box}background:#F4F2EF;display:flex;align-items:center;justify-content:center;font-size:${fs}px;font-weight:700;color:#999;">${label}</div>`;
      if (!yid && !isImg) return iconBox;
      const src = yid ? `https://img.youtube.com/vi/${yid}/hqdefault.jpg` : esc(u);
      const ph = `<div style="position:absolute;inset:0;display:flex;align-items:center;justify-content:center;font-size:${fs}px;font-weight:700;color:#999;">${label}</div>`;
      const img = `<img src="${src}" style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover;" onerror="this.style.display='none'">`;
      const pd = Math.round(h * 0.4);
      const play = isVid ? `<div style="position:absolute;inset:0;display:flex;align-items:center;justify-content:center;pointer-events:none;"><div style="width:${pd}px;height:${pd}px;background:rgba(0,0,0,.55);border-radius:50%;display:flex;align-items:center;justify-content:center;color:#fff;font-size:${Math.round(pd * 0.55)}px;">▶</div></div>` : '';
      return `<a href="${esc(u)}" target="_blank" rel="noopener" title="${isVid ? '영상 열기' : '원본 이미지 열기'}" style="position:relative;display:block;${box}overflow:hidden;background:#F4F2EF;text-decoration:none;">${ph}${img}${play}</a>`;
    }

    // ── 성과 요약 리포트: HTML 렌더 (자체 완결·인쇄용) ──
```

## Out of Scope (YAGNI)

- `이미지링크`/`meta['링크']` 데이터 소스 자체 변경(렌더만 수정).
- 비-YouTube 영상 호스트(Vimeo 등) 썸네일 — 현재 데이터는 YouTube. 비대응 URL은 아이콘 폴백으로 graceful.
- `.tt` 미사용 CSS 제거(요약 리포트) — 무해한 dead CSS, 렌더 영향 없음(최종 리뷰 트리아지 대상).
- 결과표 인라인 미리보기(대시보드 화면) 변경 — 추출물 HTML만 대상.
