# 장르별 AI 프롬프트 (Stage 3) 구현 플랜

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tagger.py`에 장르별 System Instruction 시스템을 추가하고, `main.py`가 타이틀별 게임 컨텍스트 MD를 Gemini 태깅 시 자동 주입하도록 한다.

**Architecture:** `GENRE_INSTRUCTIONS` dict로 장르 ID → (instruction, version_suffix) 매핑. `prompt_version(genre)` 이 장르별 다른 문자열을 반환해 `cache.py` 변경 없이 캐시 격리. `main.py`는 titles.json의 `_pipeline_genre`·`_pipeline_game_context_file`을 읽어 태깅 시 extra_context 앞에 게임 컨텍스트를 prepend.

**Tech Stack:** Python 3.11+, Pydantic, Gemini API (google-genai), pytest

## Global Constraints

- `cache.py` 수정 금지 — 캐시 키는 `sha256::prompt_version_string` 구조 그대로 유지
- `_pipeline_prompt_version_pin` 동작 유지 — pin 있으면 `prompt_version(genre)` 전체 덮어씀
- 펩 히어로즈 기존 캐시 무효화 금지 — `prompt_version("character_collection_rpg")`은 새 suffix 포함하되 기존 캐시는 버전 문자열이 달라지므로 자연 무효화됨 (의도된 동작)
  - **단, 펩 기존 태깅 결과가 유효하다면 버전 문자열을 바꾸지 말 것**: 펩 pin이 있으면 pin이 우선이므로 영향 없음. pin 없는 펩은 suffix 추가로 캐시 miss 발생 → 재태깅됨. 이는 **의도된 동작**이지만 사용자가 수락해야 함. 재태깅이 부담이면 `_pipeline_prompt_version_pin`을 현행 버전으로 설정해 동결 가능.
- 게임 컨텍스트 MD 경로는 repo root(`cloop_dashboard/`) 기준 상대경로
- `pipeline/game_context/` 디렉터리에 MD 파일 저장
- graceful: `_pipeline_game_context_file` 없거나 파일 없으면 WARNING 출력 후 태깅 계속
