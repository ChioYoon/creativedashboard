# 리포트 분석형 강화 Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 요약 리포트에 "기간 대비 변화(KPI 델타)"와 "주목할 소재(급등·급락·신규)"를 더하고, 리포트 생성 시 비교 기간을 지정하는 다이얼로그를 붙인다. (Phase 1 = 규칙 기반, AI 내러티브 전.)

**Architecture:** 기존 `buildFatiguePeriodScores`(기간별 소재 점수)를 재사용하는 공유 엔진 `computeReportComparison`이 두 기간의 KPI 델타·무버를 산출한다. 요약 리포트 함수가 이 결과를 선택적으로 받아 델타 배지·무버 섹션을 렌더한다. 다이얼로그가 현재/비교 기간을 모아 엔진→리포트로 넘긴다. 전부 `step1_integrated.html` 인라인 JS.

**Tech Stack:** 정적 HTML/바닐라 JS 단일 파일. 빌드 없음. 검증 = preview MCP + pytest.

**Spec:** docs/superpowers/specs/2026-07-07-리포트-분석형-강화-design.md (Phase 1 부분)

## Global Constraints

- 비교 엔진/리포트는 `buildFatiguePeriodScores(creatives, winStart, winEnd, layer, weights, gcamps, mcamps)` 재사용 — 신규 집계 로직 금지. 반환 소재 객체 필드: `{key, 유형, 이미지링크, 전환, 비용, 노출수, CPA, TotalScore, 등급, ...}`.
- 델타 방향: 전환·평균점수는 높을수록 개선(▲녹/▼적).
- `comparison` 인자는 **선택적** — 없으면(undefined) 요약 리포트는 기존 스냅샷 동작(하위호환). 버튼이 바로 exportSummaryReport() 호출해도 정상.
- 비교 기간 기본값 = 선택 기간 직전 동일 길이. 날짜 없으면 비교 생략(hasPrev=false).
- prev 데이터 0 → `hasPrev=false`, 델타 `deltaPct=null`(—표시), 무버 newcomers 생략. 리포트 정상 생성.
- 가중치 = 현재 슬라이더(`conversionWeight`/`cpaWeight`/`ipmWeight`/`roasWeight`) 정규화(합=1).
- 단일 파일 `step1_integrated.html`. 프로젝트 컨벤션 = main 브랜치 SDD. JS 단위 프레임워크 없음 → preview eval 검증.

```js
    // ── 리포트 기간 비교 엔진 (buildFatiguePeriodScores 재사용) ──
    function computeReportComparison(creatives, curWin, prevWin, layer, weights) {
      const cur = buildFatiguePeriodScores(creatives, curWin.start, curWin.end, layer, weights);
      const prev = (prevWin && prevWin.start && prevWin.end)
        ? buildFatiguePeriodScores(creatives, prevWin.start, prevWin.end, layer, weights) : [];
      const hasPrev = prev.length > 0;
      const prevMap = {}; prev.forEach(o => { prevMap[o.key] = o; });
      const sum = (arr, f) => arr.reduce((s, o) => s + (Number(f(o)) || 0), 0);
      const avg = (arr, f) => arr.length ? sum(arr, f) / arr.length : 0;
      const mk = (c, p) => ({ cur: c, prev: p, deltaAbs: c - p, deltaPct: (hasPrev && p) ? (c - p) / p * 100 : null });
      const kpiDeltas = {
        전환:   mk(sum(cur, o => o.전환),   sum(prev, o => o.전환)),
        비용:   mk(sum(cur, o => o.비용),   sum(prev, o => o.비용)),
        노출수: mk(sum(cur, o => o.노출수), sum(prev, o => o.노출수)),
        avgScore: mk(avg(cur, o => o.TotalScore), avg(prev, o => o.TotalScore)),
      };
      const withDelta = cur.filter(o => prevMap[o.key]).map(o => ({
        key: o.key, thumb: o.이미지링크 || '', type: o.유형 || '',
        scoreCur: o.TotalScore, scorePrev: prevMap[o.key].TotalScore, delta: o.TotalScore - prevMap[o.key].TotalScore,
      }));
      const risers  = withDelta.filter(x => x.delta > 0).sort((a, b) => b.delta - a.delta).slice(0, 3);
      const fallers = withDelta.filter(x => x.delta < 0).sort((a, b) => a.delta - b.delta).slice(0, 3);
      const newcomers = hasPrev
        ? cur.filter(o => !prevMap[o.key]).sort((a, b) => (b.TotalScore || 0) - (a.TotalScore || 0)).slice(0, 3)
            .map(o => ({ key: o.key, thumb: o.이미지링크 || '', type: o.유형 || '', scoreCur: o.TotalScore }))
        : [];
      return { curWin, prevWin, hasPrev, kpiDeltas, movers: { risers, fallers, newcomers } };
    }

```

```js
    function defaultPrevWindow() {
      const s = document.getElementById('startDate')?.value, e = document.getElementById('endDate')?.value;
      if (!s || !e) return { start: '', end: '' };
      const sd = new Date(s), ed = new Date(e);
      const lenDays = Math.round((ed - sd) / 86400000) + 1;
      const pe = new Date(sd); pe.setDate(pe.getDate() - 1);
      const ps = new Date(pe); ps.setDate(ps.getDate() - (lenDays - 1));
      const iso = d => d.toISOString().slice(0, 10);
      return { start: iso(ps), end: iso(pe) };
    }
    function getReportWeights() {
      const g = id => { const el = document.getElementById(id); return el ? Number(el.value) : 0; };
      const c = g('conversionWeight'), p = g('cpaWeight'), i = g('ipmWeight'), r = g('roasWeight');
      const tot = (c + p + i + r) || 1;
      return { conv: c / tot, cpa: p / tot, ipm: i / tot, roas: r / tot };
    }
    function openReportDialog() {
      if (!window.currentCreatives || !window.currentCreatives.length) {
        alert('분석 결과가 없습니다. 점수 계산을 먼저 실행해 주세요.');
        return;
      }
      const s = document.getElementById('startDate')?.value, e = document.getElementById('endDate')?.value;
      document.getElementById('reportCurPeriod').textContent = (s && e) ? `${s} ~ ${e}` : '전체 기간';
      const pw = defaultPrevWindow();
      document.getElementById('reportPrevStart').value = pw.start;
      document.getElementById('reportPrevEnd').value = pw.end;
      document.getElementById('reportDialog').style.display = 'flex';
    }
    function closeReportDialog() { document.getElementById('reportDialog').style.display = 'none'; }
    function generateSummaryReport() {
      const s = document.getElementById('startDate')?.value, e = document.getElementById('endDate')?.value;
      const ps = document.getElementById('reportPrevStart').value, pe = document.getElementById('reportPrevEnd').value;
      const layer = window.currentAnalysisLayer || 'ads';
      const curWin = { start: s, end: e };
      const prevWin = (ps && pe) ? { start: ps, end: pe } : null;
      const cmp = computeReportComparison(window.currentCreatives, curWin, prevWin, layer, getReportWeights());
      closeReportDialog();
      exportSummaryReport(cmp);
    }
```
