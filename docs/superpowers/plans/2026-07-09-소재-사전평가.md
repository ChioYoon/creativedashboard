# 소재 사전평가 (기능 2) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 신규 소재(이미지)를 업로드하면 선택 타이틀의 누적 성과 패턴에 대조해 정성 등급 + 근거 태그 + 개선 가이드를 집행 전에 제시하는 `pre_eval.html` 페이지.

**Architecture:** 정적 사이트 클라이언트 사이드. 신규 `pre_eval.html`이 공용 모듈(`js/data-source.js` 타이틀·데이터 로드, `js/gemini-api.js` 키·비전 호출)을 재사용. 흐름: ① 프런트가 선택 타이틀 데이터로 우수/리스크 태그(lift) 산출 → ② Gemini 비전이 이미지 태깅 + 인사이트/개선 작성(JSON) → ③ 프런트가 태그 매칭으로 정성 등급 결정론적 산출 → ④ 1a 카드 스타일로 렌더.

**Tech Stack:** 순수 HTML/JS, Gemini 2.5 Flash 비전(inlineData base64), localStorage(키).

## Global Constraints

- **정성 등급만**(유망/보통/개선필요) — 정밀 성공률 % 금지. "시각 신호 + 타이틀 소재 N개 성과 패턴 기반 **방향성 참고** · 실제 성과는 집행 검증 필요" 안내 필수.
- **등급은 프런트가 결정론적 산출**(태그-lift 매칭), Gemini는 태깅 + 언어(인사이트/개선)만. Gemini에게 등급을 맡기지 않음.
- **기존 `callGeminiAPI` 무회귀** — 비전은 신규 함수 `callGeminiVision`로만 추가. 기존 텍스트 호출 경로 불변.
- **입력은 이미지만**(v1). `accept="image/*"`, 용량 상한 10MB.
- **택소노미는 `pipeline/schemas.py` Enum과 동기화** — 프런트 상수에 `// SYNC: pipeline/schemas.py` 주석 명시.
- **태그 매칭은 정규화 후 비교**(`normTag`) — 저장값(예: '캐릭터 액션/전투 연출')과 스키마 라벨('캐릭터 액션·전투 연출')의 구분자 차이를 흡수.
- **엣지 폴백 필수**: 무키(실행 차단+안내) / 비교 소재 4개 미만(등급 생략, 태그+인사이트만) / JSON 파싱 실패(원문 표시) / 이미지 형식·용량.
- **검증 방식**: 프런트 JS 자동 테스트 하네스 없음. 순수 함수(computeTitlePattern·gradeCreative·normTag)는 preview 콘솔에서 합성 데이터로 단위 검증, 나머지는 preview 런타임. 실 Gemini 비전 호출은 사용자 키 환경서 확인.

- [ ] **Step 1: `callGeminiVision` 추가**

`js/gemini-api.js`에서 `callGeminiAPI` 함수(끝 `}` 라인, 현재 199줄 부근) **바로 뒤**에 추가. 기존 `callGeminiAPI`는 한 글자도 바꾸지 말 것(무회귀). fetch/에러/파싱 루프는 `callGeminiAPI`와 동일 패턴을 자체 포함(격리 목적의 의도적 중복).

```javascript
/* ──────────────────────────────────────
   3-A. 비전 호출 (이미지 + 프롬프트) — 소재 사전평가 전용
   ※ 기존 callGeminiAPI(텍스트 전용)와 분리. inlineData(base64) part 추가.
────────────────────────────────────── */
async function callGeminiVision(prompt, image, { maxTokens = 2048, temperature = 0.4, topP = GEMINI_CONFIG.TOP_P } = {}) {
  const apiKey = GeminiKeyManager.get();
  if (!apiKey) throw new Error('API_KEY_MISSING');
  if (!image || !image.data || !image.mimeType) throw new Error('IMAGE_MISSING');

  const url = `${GEMINI_CONFIG.BASE_URL}/${GEMINI_CONFIG.MODEL}:generateContent?key=${apiKey}`;
  const body = {
    contents: [{ parts: [
      { inlineData: { mimeType: image.mimeType, data: image.data } },
      { text: prompt },
    ] }],
    generationConfig: { maxOutputTokens: maxTokens, temperature, topP, thinkingConfig: { thinkingBudget: 0 } },
    safetySettings: [
      { category: 'HARM_CATEGORY_HARASSMENT',        threshold: 'BLOCK_NONE' },
      { category: 'HARM_CATEGORY_HATE_SPEECH',       threshold: 'BLOCK_NONE' },
      { category: 'HARM_CATEGORY_SEXUALLY_EXPLICIT', threshold: 'BLOCK_NONE' },
      { category: 'HARM_CATEGORY_DANGEROUS_CONTENT', threshold: 'BLOCK_NONE' },
    ],
  };

  for (let attempt = 0; attempt <= 1; attempt++) {
    let res;
    try {
      res = await fetch(url, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(body) });
    } catch (networkErr) {
      if (attempt === 1) throw new Error(`네트워크 오류: ${networkErr.message}`);
      await new Promise(r => setTimeout(r, 1000));
      continue;
    }
    if (!res.ok) {
      let apiMsg = '';
      try { apiMsg = (await res.json())?.error?.message || ''; } catch (_) {}
      switch (res.status) {
        case 429: throw new Error('RATE_LIMIT');
        case 400: throw new Error(`잘못된 요청(400): ${apiMsg || '이미지 또는 파라미터를 확인하세요.'}`);
        case 403: throw new Error('INVALID_API_KEY');
        case 500: case 503: throw new Error(`Gemini 서버 오류(${res.status}): 잠시 후 다시 시도하세요.`);
        default: throw new Error(`HTTP ${res.status}: ${apiMsg || res.statusText}`);
      }
    }
    const json = await res.json();
    const candidate = json?.candidates?.[0];
    const text = candidate?.content?.parts?.[0]?.text;
    const finishReason = candidate?.finishReason || 'UNKNOWN';
    console.log(`[GeminiVision] finishReason: ${finishReason} | 출력길이: ${(text||'').length}자`);
    if (!text) throw new Error(`응답 없음 (사유: ${finishReason})`);
    return text.trim();
  }
}
```

    hypothesis: ['높은 CTR 예상—강한 후킹','높은 CVR 예상—명확한 가치','낮은 관련성 위험—정보 부족','낮은 전환 위험—행동 유도 약함','특정 타겟에 강하게 반응','범용 어필(Mass-market)','피로도 빠를 위험—변주 필요'],
  };
  const NEGATIVE_HYPOTHESES = ['낮은 관련성 위험—정보 부족','낮은 전환 위험—행동 유도 약함','피로도 빠를 위험—변주 필요'];

  // 저장값·스키마 라벨의 구분자 차이(/··() 공백)를 흡수해 매칭.
  function normTag(s) { return String(s == null ? '' : s).replace(/[\s·・/()（）\[\]]/g, ''); }
  function _hasTag(list, tag) { const n = normTag(tag); return (list || []).some(x => normTag(x) === n); }

  // 타이틀 소재 → 우수/리스크 태그. 소재 4개 미만이면 insufficient.
  function computeTitlePattern(creatives) {
    const valid = (creatives || []).filter(c => c && c.scores && c.scores.total != null);
    const n = valid.length;
    if (n < 4) return { n, winnerTags: [], riskTags: [], insufficient: true };
    const sorted = valid.slice().sort((a, b) => b.scores.total - a.scores.total);
    const half = Math.floor(n / 2);
    const winners = sorted.slice(0, half), losers = sorted.slice(n - half);
    const rate = (cohort, tag) => cohort.filter(c => _hasTag(c.strengths, tag)).length / (cohort.length || 1);
    const allStrengths = [...new Set(valid.flatMap(c => c.strengths || []))];
    const winnerTags = allStrengths
      .map(tag => ({ tag, lift: +(rate(winners, tag) - rate(losers, tag)).toFixed(2) }))
      .filter(o => o.lift >= 0.2).sort((a, b) => b.lift - a.lift).map(o => o.tag);
    const wCount = {};
    losers.forEach(c => (c.weaknesses || []).forEach(w => { wCount[w] = (wCount[w] || 0) + 1; }));
    const thr = Math.ceil(losers.length / 3);
    const riskTags = Object.keys(wCount).filter(w => wCount[w] >= thr);
    return { n, winnerTags, riskTags, insufficient: false };
  }

  // 신규 소재 태그 × 타이틀 패턴 → 정성 등급 (결정론적).
  function gradeCreative(tags, pattern) {
    const s = tags.strengths || [], w = tags.weaknesses || [];
    const matchedWinners = (pattern.winnerTags || []).filter(t => _hasTag(s, t));
    const missedWinners  = (pattern.winnerTags || []).filter(t => !_hasTag(s, t));
    const heldRisks      = (pattern.riskTags || []).filter(t => _hasTag(w, t));
    let grade;
    if (matchedWinners.length >= 2 && heldRisks.length === 0) grade = '유망';
    else if (heldRisks.length >= 2 || (heldRisks.length >= 1 && matchedWinners.length === 0)) grade = '개선필요';
    else grade = '보통';
    return { grade, matchedWinners, missedWinners, heldRisks };
  }

  function buildVisionPrompt(pattern, gameCtx, concept) {
    const T = TAG_TAXONOMY;
    const list = a => a.join(' / ');
    const L = [];
    L.push('당신은 모바일 게임 UA 소재 분석가입니다. 첨부 이미지를 분석해 아래 고정 택소노미의 정확한 한글 라벨로만 태깅하고, JSON으로만 응답하세요(다른 텍스트 금지).');

      L.push(`[이 타이틀 저효율 공통 약점] ${pattern.riskTags.join(', ') || '없음'}`);
    }
    if (concept) L.push(`[마케터가 의도한 컨셉] ${concept}`);
    L.push('종합인사이트: 이 소재의 시각 신호를 위 패턴과 대조해 2~3문장. 개선가이드: 놓친 우수 요소 보완·리스크 제거 구체책 2~3개(개조식). 근거 없는 과장 금지.');

  function parseVisionJson(raw) {
    if (!raw) return null;
    let s = String(raw).replace(/```json|```/g, '').trim();
    const a = s.indexOf('{'), b = s.lastIndexOf('}');
    if (a === -1 || b === -1) return null;
    try { return JSON.parse(s.slice(a, b + 1)); } catch (_) { return null; }
  }

  async function _peGameContext(titleId) {
    try {
      const res = await fetch(`pipeline/game_context/${titleId}.md`, { cache: 'no-store' });
      if (!res.ok) return '';
      return (await res.text()).slice(0, 1200);
    } catch (_) { return ''; }
  }

  window.runPreEval = async function runPreEval() {
    const status = document.getElementById('peStatus'), result = document.getElementById('peResult');
    const titleId = document.getElementById('peTitle').value;
    const img = window.__preEvalImage;
    if (!img) { status.textContent = '이미지를 먼저 업로드하세요.'; return; }

      return;
    }

    try {

      const creatives = (normalized && normalized.rows) || [];

      const raw = await callGeminiVision(buildVisionPrompt(pattern, gameCtx, concept), img, { maxTokens: 1400, temperature: 0.4 });
      const parsed = parseVisionJson(raw);

      const tags = { strengths: parsed.strengths || [], weaknesses: parsed.weaknesses || [] };
      const graded = pattern.insufficient ? null : gradeCreative(tags, pattern);
