# Batch B — 소재 목록 표 UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 소재 목록 표를 ② 두 점수 상시 표시 ⑤ 전 컬럼 정렬 ⑥ 선택 소재 표뷰 필터로 개선.

**Architecture:** 전부 `step1_integrated.html` 인라인. ② 행 렌더 override + 레이어 숨김 CSS 제거, ⑤ 기존 `attachHeaderSort` MAP·`sortByColumn` 확장, ⑥ 체크박스 컬럼 + 선택 Set + 토글 필터.

**Tech Stack:** 바닐라 JS/CSS 인라인. preview 서버 + `preview_eval`(캐시 우회 `?_=<ts>`).

## Global Constraints

- **표시·정렬·필터만 변경** — 데이터·점수 산식·파이프라인 무변경.
- ② `총점`/`등급` 컬럼은 항상 Google Ads 기준(데이터 없으면 `—`). `MMP 점수`(col-mmp)·`성과`(col-pctile)는 데이터 게이트(show-mmp/show-pctile)만 유지, 레이어 숨김 제거.
- ⑥ 선택은 **표 뷰 필터만** — 상단 통계카드·요약·산식 불변.
- 검증은 preview(`cloop-static`, 8765), 인라인이라 `?_=<ts>` 새 문서 로드.

- [ ] **Step 4: 선택 wiring (위임 리스너, 멱등)**

신규 함수 + 1회 바인딩(예: `attachHeaderSort` 끝 또는 displayScoringResults 에서 `attachRowSelection()` 호출):
```js
    function attachRowSelection() {
      const tbody = document.getElementById('tableBody');
      const all = document.getElementById('selectAllRows');
      const tog = document.getElementById('selectedOnlyToggle');
      if (tbody && !tbody.dataset.selBound) {
        tbody.dataset.selBound = '1';
        tbody.addEventListener('change', (e) => {
          const cb = e.target.closest('.row-select'); if (!cb) return;
          const k = cb.dataset.rowkey;
          const s = window._selectedKeys || (window._selectedKeys = new Set());
          if (cb.checked) s.add(k); else s.delete(k);
          const cnt = document.getElementById('selectedCount'); if (cnt) cnt.textContent = s.size ? `(${s.size}개 선택)` : '';
          const t = document.getElementById('selectedOnlyToggle');
          if (t && t.checked) renderResultTableRows(window.currentCreatives);
        });
      }
      if (all && !all.dataset.selBound) {
        all.dataset.selBound = '1';
        all.addEventListener('change', () => {
          const s = window._selectedKeys || (window._selectedKeys = new Set());
          document.querySelectorAll('#tableBody .row-select').forEach(cb => {
            cb.checked = all.checked; if (all.checked) s.add(cb.dataset.rowkey); else s.delete(cb.dataset.rowkey);
          });
          const cnt = document.getElementById('selectedCount'); if (cnt) cnt.textContent = s.size ? `(${s.size}개 선택)` : '';
          const t = document.getElementById('selectedOnlyToggle'); if (t && t.checked) renderResultTableRows(window.currentCreatives);
        });
      }
      if (tog && !tog.dataset.selBound) {
        tog.dataset.selBound = '1';
        tog.addEventListener('change', () => renderResultTableRows(window.currentCreatives));
      }
    }
```
`displayScoringResults` 가 표를 처음 렌더한 직후 `attachRowSelection()` 1회 호출(멱등이라 반복 안전).
