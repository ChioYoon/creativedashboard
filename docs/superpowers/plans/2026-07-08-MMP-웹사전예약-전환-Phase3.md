# MMP 웹 사전예약 전환 — Phase 3 (프런트 표시) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 등록 기준 타이틀(ZEUS)의 MMP 레이어를 화면에서 등록수 기준으로 표시한다 — 전환=등록, CPA=비용/등록, IPM=등록/노출, ROAS·D1잔존은 N/A, 라벨은 `convBasis`로 재라벨. 설치 타이틀은 무변경.

**Architecture:** Phase 2가 산출한 `mmp_quality_score.convBasis`("사전예약"|"설치")를 프런트 단일 스위치로 사용. MMP 표시의 단일 소스인 `creativeLayerView`/`layerLabels`(js/layer-metrics.js)와 모달 MMP 섹션(step1_integrated.html)에 등록 분기를 넣는다. 점수·등급은 이미 등록 기준이라 표시값·라벨만 조정.

**Tech Stack:** Vanilla JS(인라인 + js/layer-metrics.js 공용 모듈). 프런트 JS 테스트 하니스 없음 — 정적 grep + 컨트롤러 preview MCP 런타임 검증. pytest는 무관(114+, 회귀 확인만).

## Global Constraints

- 단일 스위치: `mmp_quality_score.convBasis === '사전예약'` → 등록 기준. 아니면 설치(기존).
- 등록 기준 표시: 전환=`mmp_conversions`, CPA=`mmp_cost/mmp_conversions`, IPM=`mmp_conversions/mmp_impressions×1000`, ROAS=null(N/A), D1잔존=N/A. 점수·등급=`mmp_quality_score`(Phase2, 그대로).
- 설치 기준 타이틀·Google Ads 레이어는 **무변경**(하위호환).
- convBasis는 타이틀 단위 균일(모든 소재 동일) — 타이틀 레벨 감지는 `currentCreatives` 스캔.
- 대상 파일: `js/layer-metrics.js` + `step1_integrated.html`.
- 브랜치 `main`. 각 Task 커밋, push는 사용자 승인 후. 시크릿 미포함.
- 검증: 컨트롤러가 preview에서 **합성 데이터**(소재에 `mmp_conversions` + `mmp_quality_score.convBasis='사전예약'` 주입)로 표시 확인 — 실 zeus.json은 파이프라인 재실행 전이라 등록 데이터 없음.
