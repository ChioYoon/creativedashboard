# Drive 폴더 링크 폴백 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 미리보기(Google Ads asset URL)가 없는 소재에, 타이틀별 Google Drive 공유 폴더 링크 버튼(`📁 Drive`)을 폴백으로 노출한다.

**Architecture:** 순수 프론트엔드 변경. `js/titles.json`에 타이틀별 `drive_folder_url` 1개 추가 → 대시보드가 런타임에 매니페스트를 읽어 현재 타이틀의 URL을 전역(`window.currentDriveFolderUrl`)에 보관 → 미리보기 렌더 3곳에서 URL 없는 소재에 공용 헬퍼 `driveFolderButtonHtml()`로 버튼 렌더. 파이프라인·재태깅·스코어 변경 없음.

**Tech Stack:** 정적 HTML + 인라인 JS (`step1_integrated.html`), `js/titles.json`, `js/data-source.js`. JS 단위 테스트 하니스 없음 → 검증은 preview MCP 도구(브라우저)로 수행.

## Global Constraints

- 파이프라인·스코어·태깅·캐시 변경 금지 (순수 프론트엔드).
- 필드명은 `drive_folder_url` (프론트엔드가 직접 소비 — `_pipeline_` 접두사 없음).
- 폴백은 **미리보기 없는 소재에만** — 이미지/영상 미리보기가 있는 소재는 기존 동작 그대로.
- `drive_folder_url` 없는 타이틀(펩 등)은 기존 placeholder 동작 유지 (회귀 금지).
- 새 탭은 `window.open(url, '_blank', 'noopener')`로 격리.
- 도원암귀 폴더 URL(확정값): `https://drive.google.com/drive/folders/1N3lnsfKTeiYLfT-OWwZ1aI-ou74u9pDJ`
- 3개 렌더 지점 모두 동일 폴백 규칙 적용 (메인 랭킹표 / 점수 상세표 / 피로도표).
- DRY: 버튼 HTML은 공용 헬퍼 `driveFolderButtonHtml()` 1곳에서만 생성.

```javascript
    function driveFolderButtonHtml() {
      const url = window.currentDriveFolderUrl || '';
      if (!url) return '';
      const safe = url.replace(/'/g, "\\'");
      return `<button type="button" onclick="window.open('${safe}','_blank','noopener')" title="공유 드라이브 폴더에서 이 소재를 찾아보세요" style="cursor:pointer;font-size:11px;font-weight:600;color:#666;background:#F4F2EF;border:1px solid #e5e0d8;border-radius:6px;padding:6px 8px;display:inline-flex;align-items:center;gap:3px;white-space:nowrap;">📁 Drive</button>`;
    }
```
