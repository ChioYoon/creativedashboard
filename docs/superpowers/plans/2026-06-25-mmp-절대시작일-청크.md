# MMP(Airbridge) 절대 시작일 + 청크 fetch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MMP(Airbridge)도 절대 시작일(`_pipeline_kpi_start_date`)부터 수집하도록 하고, Airbridge actuals 쿼리 범위 제한을 90일 청크 분할로 회피한다.

**Architecture:** `_pipeline_google_ads_start_date`를 공통 `_pipeline_kpi_start_date`로 일반화(Google Ads+MMP). MMP 윈도우도 `resolve_window` 사용. `fetch_mmp_window`가 90일 초과 범위를 ≤90일 청크로 분할 fetch 후 병합·dedup.

**Tech Stack:** Python 3.12, pytest. Airbridge actuals API(범위 제한: 81·159일 OK, 236일 400).

## Global Constraints

- `_pipeline_kpi_start_date` = Google Ads + MMP **공통** 절대 시작일. 미설정 시 기존 window_days(하위 호환).
- `fetch_mmp_window` 90일 초과 → ≤90일 청크 분할·병합·dedup(key=creative_name·channel·campaign_name·date). 90일 이하 → 단일 쿼리(기존 동작 유지).
- `MAX_CHUNK_DAYS = 90` (실측 81일 성공 + retention 92일 청크 패턴 정합).
- `last_fetch_truncated` = 청크 중 하나라도 truncated.
- `resolve_window` 재사용(Google Ads 79edc84에서 추가). pepp `_pipeline_kpi_start_date: "2025-11-01"`.

- [ ] **Step 3: 구현** (`pipeline/sources/airbridge.py`)

`fetch_mmp_window`(216-254 현행)을 아래로 교체 — 본문을 `_fetch_window_single`로 추출하고 `fetch_mmp_window`를 청크 래퍼로:

```python
    MAX_CHUNK_DAYS = 90

    def fetch_mmp_window(self, start: date, end: date,
                         exclude_channels: Optional[set] = None) -> list[CreativeMmpDaily]:
        """기간 내 Actuals → CreativeMmpDaily. Airbridge actuals 쿼리 범위 제한 회피 위해
        ≤90일 청크로 분할 fetch 후 병합·dedup. 90일 이하면 단일 쿼리(기존 동작)."""
        out: list[CreativeMmpDaily] = []
        seen: set = set()
        self.last_fetch_truncated = False
        cs = start
        while cs <= end:
            ce = min(cs + timedelta(days=self.MAX_CHUNK_DAYS - 1), end)
            rows, truncated = self._fetch_window_single(cs, ce, exclude_channels)
            if truncated:
                self.last_fetch_truncated = True
            for r in rows:
                key = (r.creative_name, r.channel, r.campaign_name, str(r.date))
                if key not in seen:
                    seen.add(key)
                    out.append(r)
            cs = ce + timedelta(days=1)
        return out

    def _fetch_window_single(self, start: date, end: date,
                             exclude_channels: Optional[set] = None) -> tuple[list, bool]:
        """단일 기간 Actuals 쿼리(+페이지네이션). (rows, truncated) 반환."""
        exclude = set(exclude_channels) if exclude_channels else set(DEFAULT_EXCLUDE_CHANNELS)
        body = {
            "from": start.isoformat(), "to": end.isoformat(),
            "groupBys": ["ad_creative", "channel", "campaign", "event_date"],
            "metrics": self._query_metrics(), "filters": [], "sorts": [],
        }
        task_id = self._create_task(body)
        page = self._poll_until_success(task_id)

        out: list[CreativeMmpDaily] = []
        PAGE_SIZE = 100
        MAX_PAGES = 100
        skip = 0
        pages = 0
        end_iso = end.isoformat()
        while True:
            out += parse_actuals_rows(page, self.metrics_map, exclude,
                                      default_date=end_iso, fx_rate=self.usd_to_krw)
            pages += 1
            pg = page.get("pagination") or {}
            if not pg.get("hasNext") or pages >= MAX_PAGES:
                break
            skip += PAGE_SIZE
            page = self._get_page(task_id, skip=skip, size=PAGE_SIZE)

        pg = page.get("pagination") or {}
        truncated = bool(pg.get("hasNext"))
        if truncated:
            print(f"   [airbridge] ⚠️ 청크 {start}~{end}: {pg.get('totalCount')}행 중 "
                  f"{pages * PAGE_SIZE}행만 수신 (10,000행 상한) — Raw Data Export 필요.", file=sys.stderr)
        return out, truncated
```
