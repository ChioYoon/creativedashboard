# 리포트 분석형 강화 Phase 2 (AI 내러티브) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 요약 리포트에 "AI 코멘트"(주간/월간 보고용 산문)를 추가한다 — 기존 Gemini 연동(`callGeminiAPI`)을 확장해 KPI 델타·무버·top소재를 요약한 코멘트를 생성하고, 없으면 우아하게 생략.

**Architecture:** 순수 프롬프트 빌더 `buildReportNarrativePrompt`(테스트 가능) + async `buildReportNarrative`(키 있으면 `callGeminiAPI` 호출, 없음/실패 시 ''). `generateSummaryReport`가 async로 바뀌어 리포트 생성 전 로딩 표시하며 내러티브를 받아 `exportSummaryReport(comparison, narrative)`로 넘기고, 렌더가 "AI 코멘트" 섹션을 표시한다. 전부 `step1_integrated.html` 인라인 JS.

**Tech Stack:** 정적 HTML/바닐라 JS 단일 파일 + 기존 `js/gemini-api.js`(callGeminiAPI/GeminiKeyManager). 검증 = preview MCP + pytest.

**Spec:** docs/superpowers/specs/2026-07-07-리포트-분석형-강화-design.md (⑤ AI 내러티브 부분)

## Global Constraints

- AI 내러티브 = 기존 `callGeminiAPI(prompt, opts)`(js/gemini-api.js, 텍스트 반환, `API_KEY_MISSING` throw) + `GeminiKeyManager.isSet()` 재사용. 신규 API 클라이언트 금지.
- **키 없음/호출 실패 → `narrative=''` → "AI 코멘트" 섹션 생략** (리포트는 정상 생성). 절대 예외로 리포트 생성이 막히면 안 됨.
- `generateSummaryReport`는 async — Gemini 호출 동안 `showLoadingIndicator('AI 코멘트 생성 중...')`, 완료 시 `hideLoadingIndicator()`.
- 내러티브는 평문(마크다운 없이) 요청. 렌더 시 `esc()` + `\n→<br>`.
- Phase 1의 `computeReportComparison`·`buildSummaryReportData(creatives, comparison[, narrative])`·`exportSummaryReport`·다이얼로그 재사용. comparison/narrative 모두 선택적(하위호환).
- 단일 파일 `step1_integrated.html`. 프로젝트 컨벤션 = main 브랜치 SDD. pytest 114 passed.

```js
    function buildReportNarrativePrompt(data) {
      const k = data.kpis, cmp = data.comparison;
      const dpct = d => (d && d.deltaPct != null) ? `(전 기간 대비 ${d.deltaAbs >= 0 ? '+' : ''}${Math.round(d.deltaPct)}%)` : '';
      const L = [];
      L.push('당신은 컴투스 R마케팅팀의 UA 소재 분석가입니다. 아래 데이터로 주간/월간 보고에 넣을 3~4문장 한국어 코멘트를 작성하세요. 과장 없이 핵심 변화·주목 소재·다음 액션을 담고, 마크다운 없이 평문으로만 쓰세요.');
      L.push(`타이틀: ${data.titleName} / 기간: ${data.period} / 레이어: ${data.layer}`);
      L.push(`핵심 지표: 소재 ${k.count}개, 평균 점수 ${k.avgScore == null ? '-' : k.avgScore.toFixed(1)}, 최우수 ${k.excellent}개, 총 전환(${k.convBasis}) ${Math.round(k.totalConv).toLocaleString()}`);
      if (cmp && cmp.hasPrev) {
        L.push(`전 기간 대비: 전환 ${Math.round(cmp.kpiDeltas.전환.cur).toLocaleString()} ${dpct(cmp.kpiDeltas.전환)}, 평균점수 ${dpct(cmp.kpiDeltas.avgScore)}`);
        const names = arr => (arr.map(m => m.key).slice(0, 3).join(', ') || '없음');
        L.push(`급등: ${names(cmp.movers.risers)} / 급락: ${names(cmp.movers.fallers)} / 신규: ${names(cmp.movers.newcomers)}`);
      }
      L.push(`Top 소재: ${data.topN.slice(0, 3).map(t => `${t.name}(점수 ${t.score == null ? '-' : t.score.toFixed(1)})`).join(', ')}`);
      return L.join('\n');
    }
    async function buildReportNarrative(comparison, creatives) {
      if (typeof GeminiKeyManager === 'undefined' || !GeminiKeyManager.isSet()) return '';
      try {
        const data = buildSummaryReportData(creatives, comparison);
        const prompt = buildReportNarrativePrompt(data);
        return await callGeminiAPI(prompt, { maxTokens: 500, temperature: 0.6 });
      } catch (e) {
        console.warn('AI 코멘트 생성 실패:', e && e.message);
        return '';
      }
    }
```

```js
    async function generateSummaryReport() {
      const s = document.getElementById('startDate')?.value, e = document.getElementById('endDate')?.value;
      const ps = document.getElementById('reportPrevStart').value, pe = document.getElementById('reportPrevEnd').value;
      const layer = window.currentAnalysisLayer || 'ads';
      const curWin = { start: s, end: e };
      const prevWin = (ps && pe) ? { start: ps, end: pe } : null;
      const cmp = computeReportComparison(window.currentCreatives, curWin, prevWin, layer, getReportWeights());
      closeReportDialog();
      let narrative = '';
      if (typeof GeminiKeyManager !== 'undefined' && GeminiKeyManager.isSet()) {
        showLoadingIndicator('AI 코멘트 생성 중...');
        try { narrative = await buildReportNarrative(cmp, window.currentCreatives); }
        finally { hideLoadingIndicator(); }
      }
      exportSummaryReport(cmp, narrative);
    }
```
