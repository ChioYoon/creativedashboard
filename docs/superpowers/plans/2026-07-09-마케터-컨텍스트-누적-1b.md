# 누적 마케터 컨텍스트 (1b) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공유·커밋되는 게임/마케터 컨텍스트(`game_context/{title}.md`)를 출력 JSON에 임베드해 보고서·사전평가가 팀 전체에 걸쳐 읽게 하고, 컨텍스트 변경 시 재태깅을 권장하는 스테일 알림을 붙인다.

**Architecture:** 파이프라인이 game_ctx를 `CreativeDataset.game_context`에 임베드 + 컨텍스트 해시를 `metrics.game_context_sha`에 기록하고 실행 시 스테일 경고. 프런트는 `js/data-source.js` `_meta`로 노출 → 보고서(§4·§5 배경 블록 주입)·사전평가(JSON에서 컨텍스트 읽기)가 소비.

**Tech Stack:** Python(pydantic·hashlib), 프런트 순수 JS.

## Global Constraints

- **무회귀:** game_context 없는 구 JSON(`_meta.game_context=''`)에선 보고서 컨텍스트 블록 생략·사전평가 컨텍스트 없이 진행 — 기존과 동일.
- **파이프라인은 사용자가 로컬 실행** — 컨텍스트 임베드·스테일 알림은 다음 파이프라인 실행 후 데이터에 반영. 구현자는 코드+pytest만(파이프라인 실행 금지).
- **재태깅은 자동 아님** — 컨텍스트 변경 시 경고만 출력, 사람이 `--no-cache`로 판단·실행. 캐시 키는 **바꾸지 않음**(현행 `sha::prompt_version` 유지).
- **보고서 컨텍스트는 §4(UA 전략)·§5(금기)만·상한 ~1500자** — 토큰 절약. 기존 `[마케터 의견]`(note) 블록은 유지(컨텍스트=배경, note=이번 보고서 의견).
- **기존 태깅·점수 로직 불변** — game_context는 출력에 추가만. `build_extra_context`(태깅 주입)는 그대로.
- **검증:** 파이프라인=pytest, 프런트=preview 런타임(합성 JSON). 실 end-to-end(파이프라인 임베드→보고서)는 사용자 실행 후.

```python
def _context_sha(text: str) -> str:
    """게임 컨텍스트 식별 해시(16자). 빈 문자열이면 ''."""
    if not text:
        return ""
    return hashlib.sha256(text.encode("utf-8")).hexdigest()[:16]


def _context_stale(prev_sha: str, cur_sha: str) -> bool:
    """이전 태깅 컨텍스트 해시와 현재가 다르면 True(둘 다 값 있을 때만)."""
    return bool(prev_sha) and bool(cur_sha) and prev_sha != cur_sha
```
