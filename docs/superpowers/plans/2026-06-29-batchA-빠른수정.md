- [ ] **Step 5: preview 검증 — ①·④ 단언**

preview 기동 후 `http://localhost:8765/step1_integrated.html?_=<timestamp>` 로드. `preview_eval`:

```js
(function(){
  var btn = document.getElementById('layerBtnMmp');
  // 툴팁 측정: data-tip 있는 헤더에 임시로 hover 상태 스타일 계산
  var th = document.querySelector('.has-tooltip[data-tip]');
  var after = th ? getComputedStyle(th, '::after') : null;
  return {
    mmpLabel: btn ? btn.textContent.trim() : '(no btn)',
    tooltip: after ? { whiteSpace: after.whiteSpace, maxWidth: after.maxWidth, wordBreak: after.wordBreak } : '(no has-tooltip)'
  };
})()
```
Expected: `mmpLabel:"MMP 기준"`, `tooltip:{ whiteSpace:"normal", maxWidth:"260px", wordBreak:"keep-all" }`.
