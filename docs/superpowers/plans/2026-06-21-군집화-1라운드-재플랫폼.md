# 군집화 1라운드(재플랫폼) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 군집화 도구(step2)를 파이프라인 JSON 자동 로드·분석 레이어 토글·Com2uS DS v2로 재플랫폼하고, step1·step2가 공용 레이어 모듈을 공유하게 한다. 군집 알고리즘은 그대로 둔다.

**Architecture:** step1의 레이어 지표 로직을 `js/layer-metrics.js`(window.LayerMetrics)로 바이트 동일 추출 → step1은 참조로 교체(동작 불변), step2는 신규 소비. step2는 `data-source.js`로 `public/data/{title}.json`을 자동 로드(재업로드 제거)하고, Com2uS DS v2(`assets/ds/colors_and_type.css`) 토큰·컴포넌트로 전면 재스타일하며, Google Ads/MMP 레이어 토글로 성과 오버레이만 전환한다.

**Tech Stack:** 바닐라 JS(ES6, 빌드 없음), Chart.js 4.4.0(기존), Com2uS DS v2(CSS 변수 + Pretendard woff2 셀프호스팅 + Noto Sans KR CDN), preview MCP(검증).

**관련 문서:** spec [2026-06-21-군집화-1라운드-재플랫폼-design.md](../specs/2026-06-21-군집화-1라운드-재플랫폼-design.md) · 로드맵 [2026-06-20-개발로드맵-재정리.md](../specs/2026-06-20-개발로드맵-재정리.md) T2.

## Global Constraints

- **하드코딩 hex 금지** — 색·간격·폰트·radius·shadow는 `colors_and_type.css`의 CSS 변수만 사용(`--brand-primary`, `--gray-*`, `--space-*`, `--radius-*`, `--shadow-*` 등).
- **무이모지** — step2 신규/재작성 UI에 유니코드 이모지 미사용(브랜드 스마일은 로고에만). 기존 이모지 정리는 본 계획 범위 밖.
- **step1 동작 불변** — 모듈 추출은 바이트 동일이어야 함. 회귀 불변값(아래)으로 매 추출 후 검증.
- **군집 알고리즘 불변** — step2의 Phase 0~4(aggregateByMaterial·iqrNoiseFilter·buildTagClusters·assignMaterialsToClusters·calcRankScores·enrichClusters)는 로직 변경 없음. 본 라운드는 데이터 입력·레이어·디자인만 바꾼다.
- **전체 기간 기준** — step2 성과 지표는 실적일 윈도우 미적용. UI에 "전체 기간 기준" 라벨 노출.
- **`.env` 등 시크릿 미커밋**(해당 변경 없음).
- **검증 = preview MCP** — JS 단위 테스트 프레임워크가 없으므로 각 태스크는 preview 서버(`cloop-static`, :8765)에서 DOM/상태 eval 로 검증한다.

```js
async function loadFromPipeline() {
  const tid = window.DataSource.readTitleFromUrl();
  if (!tid) return false;                 // ?title= 없으면 CSV 폴백
  const manifest = await window.DataSource.loadTitleManifest();
  const entry = manifest.find(t => t.id === tid);
  if (!entry || !entry.json_url) return false;
  try {
    const { normalized } = await window.DataSource.loadCreativeData('json-url', { url: entry.json_url, titleId: tid });
    ingestRows(normalized.columns, normalized.rows);   // ↓ Step 2
    return true;
  } catch (e) { console.warn('[step2] 파이프라인 로드 실패, CSV 폴백:', e.message); return false; }
}
```

- [ ] **Step 2: ingestRows — JSON rows 를 기존 csvData 형태로 정규화**

```js
function ingestRows(columns, rows) {
  // 기존 CSV 경로와 동일한 csvData 형태로 맞춘다(클러스터링 호환)
  window.__pipelineRows = rows;            // 원본 meta 보존(레이어 점수용; Task 5 에서 사용)
  csvData = { headers: columns, rows: rows };
  discoverColumns();                       // 기존 컬럼 자동분류 재사용
  renderUI();                              // 기존 렌더 재사용
}
```

- [ ] **Step 3: applyLayerScores — 활성 레이어로 소재 성과 산출 후 군집 카드/표 갱신**

각 소재(원본 row)에 활성 레이어 성과를 채우고, 기존 군집 렌더를 성과만 갱신:
```js
function applyLayerScores() {
  const rows = (window.csvData && window.csvData.rows) || [];
  if (window.currentAnalysisLayer === 'ads') {
    // Google Ads: 공용 스코어러로 전환수점수/CPA점수/IPM점수/ROAS점수/TotalScore/등급 주입(전체기간·균등가중)
    rows.forEach(c => { c._ads = c._ads || { imp: Number(c.노출수||0) }; });
    window.LayerMetrics.calculateCreativeScores(rows, 0.25, 0.25, 0.25, 0.25);
  } else {
    // MMP: 사전계산된 meta.mmp_quality_score 사용(없으면 scoreMmpItems 로 산출)
    // (Round 1 은 파이프라인 저장값 우선; 이미 row.meta.mmp_quality_score 존재)
  }
  rerenderClusterPerformance();   // ↓ Step 4
}
```
⚠️ MMP 분기는 추가 산출 없이 `row.meta.mmp_quality_score`(파이프라인 전체기간값)를 그대로 사용 — spec 의 "MMP 는 사전계산값" 결정과 일치.

- [ ] **Step 4: rerenderClusterPerformance — 군집은 그대로, 성과 표시만 레이어 값으로**

```js
function rerenderClusterPerformance() {
  // 군집 객체(window.clusters)는 유지. 각 군집의 평균점수·대표지표를 활성 레이어 creativeLayerView 로 재계산해 카드/표/차트만 갱신.
  renderClusterCards(window.clusters);   // 내부에서 creativeLayerView 사용하도록 수정
  renderMappingTable(window.clusters);
  renderCharts(window.clusters);
}
```
컬럼 라벨은 `window.LayerMetrics.layerLabels()` 사용(예: 매핑 테이블 헤더 CPA↔D1 CPI 전환). 등급 배지색은 `MMP_GRADE_STYLE`.
