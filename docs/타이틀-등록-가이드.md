# 타이틀 등록 가이드 (라이브 대시보드)

## 흐름
1. **담당자**: 공유 드라이브의 `CLOOP_타이틀_등록부` 시트에 자기 타이틀 행 추가(담당자 컬럼 7개).
2. **운영자**: `로컬 스캔 경로`·`Google Ads ID`·`MMP` 보완 후 `활성화`=Y.
3. 매일 13:00 nightly가 등록부를 읽어 `js/titles.json` 자동 생성 → 대시보드 반영.

## 담당자 입력 컬럼
- **타이틀 ID**: 영문 소문자·숫자·하이픈 (예 `newgame-us`). 대시보드 식별자.
- **타이틀명**: 표시 이름.
- **소재 폴더 링크**: 소재가 든 Google Drive 공유 폴더 URL.
- **소재 유형**: `BNR,VID`.
- **장르**: `character_collection_rpg` / `dark_fantasy_card_rpg` / (신규는 운영자 문의).
- **광고 성과 연동**: 유료 UA 집행해 성과 지표 연동하면 `Y`, 시각 분석만이면 `N`.
- **비고/요청**: 특이사항.

## 운영자 입력 컬럼
- **로컬 스캔 경로**: 소재 폴더의 PC 마운트 경로 `G:\공유 드라이브\...`.
- **Google Ads ID**: KPI=Y 시 10자리 customer ID.
- **MMP 종류 / 앱 식별자**: `Airbridge`/`AppsFlyer`/`없음` + 앱 식별자.
- **활성화**: 검토 완료 시 `Y`.

## 고급 설정 (운영자, 드묾)
`js/titles_overrides.json` 에 타이틀별 추가 (버전핀·윈도우일수 등). 등록부보다 우선.

## 설정 (1회)
- 운영자 PC env `CLOOP_REGISTRY_XLSX` = 등록부 xlsx 로컬 경로.
- 게임 컨텍스트: `pipeline/game_context/{id}.md` 에 두면 자동 연결(NotebookLM 추출).
