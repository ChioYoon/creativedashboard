# Higgsfield 생성 연동 설계 (v0)

> 브리프 → 소재 자동 생성 파이프라인 설계 · 데이터 계약
> 최종: 2026-09-12 · 회의 최종 목표(이터레이션 자동화)의 생성 단계

---

## 0. 전제·제약 (지금 상태)

- **정식 구독 미정** — 로드맵상 Higgsfield 정식 구독 결정은 ~9/30(품질+A/B 게이트 통과 후). 그 전엔 무료 크레딧 파일럿.
- **MCP 커넥터 미연결** — 현재 환경에 Higgsfield MCP 없음. 실제 생성 호출은 구독+MCP 등록 후 가능.
- **사람 게이트 필수** — 회의 결론: 완전 자동 아님. 생성물은 반드시 담당자 검수 후 집행.
- 따라서 이 문서는 **설계 + 데이터 계약**까지. 실 연동 구현은 구독·MCP 확보 후 착수.

## 1. Higgsfield 스펙 요약 (툴 조사 기준)

- 연동: **CLI · MCP 서버** 지원
- 엔진: 영상 Seedance 2.0 / 이미지 nanobanana Pro
- 비용: 이미지 ~$0.13/종 · 영상 ~$1.46/종 · 에셋 학습 ~$3/세션(15자 기준)
- 규격: 비율 16:9·9:16·1:1·4:5·21:9 / 길이 ~15초 / 다국어 텍스트·립싱크
- 소유권: 제작자 귀속(면책조항은 엔터프라이즈만 — 대형 캠페인 주의)

## 2. 파이프라인 아키텍처

```
① 위닝 판별 (대시보드)            — 이미 구축 (점수·피로도)
② 제작 브리프 생성 (대시보드)      — 이미 구축 (#15: 슬롯1~6, 브랜드·IP세이프 주입)
③ 구조화 페이로드 변환            — 신규(§3): 브리프 → Higgsfield 입력 JSON
④ 에셋 리소스 결합               — 드라이브 어셋(일러스트·인게임컷) + 브랜드 학습본
⑤ Higgsfield 생성 (MCP)          — 구독·MCP 후: 이미지/영상 생성 호출
⑥ 사람 게이트                    — 담당자 검수(브랜드·IP세이프 위반 여부) ★필수
⑦ 집행 + 성과 피드백 → ①로 (CLoop)
```
①②는 완료. ③이 다음 구현 단위(생성 툴 무관하게 유효). ⑤가 구독·MCP 의존.

## 3. 데이터 계약 — 구조화 브리프 페이로드 (핵심)

현재 브리프는 사람용 HTML. 생성 자동화엔 **기계가 읽는 JSON**이 필요. 위닝 소재 1건당:

```json
{
  "title_id": "zeus",
  "base_creative": "L-Reward-LaunchReward-02-DA",
  "type": "BNR",                          // BNR|VID → 비율·길이 결정
  "winning_elements": {                    // 유지(슬롯2)
    "hooking_strategy": "압도적 보상",
    "usp": "혜택형(무료뽑기/보상)",
    "art_style": "시네마틱 실사 합성",
    "player_motivation": "성취형",
    "strengths": ["보상 약속 명확", "강한 비주얼 임팩트"]
  },
  "improve": {                             // 변주(슬롯3)
    "weaknesses": ["장르/게임성 불분명"],
    "test_ideas": ["게임플레이 컷 추가", "명시적 CTA 추가"]
  },
  "brand": {                               // 슬롯4·6 (brand_briefs.json)
    "tone": "골드·다크 판타지",
    "characters": "제우스 / 워리어 ...",
    "slogan": "모두에게 허락된, 가장 거대한 신화",
    "cta_tone": "강렬·정복 지향"
  },
  "ip_safe": [                             // ★ negative prompt / 검수 체크리스트
    "외계 문명/테라포밍 설정 금지",
    "주적 티탄(크로노스) 한정 · 하데스 금지",
    "고채도 이펙트 남발 금지"
  ],
  "gen_params": {                          // Higgsfield 입력
    "engine": "nanobanana",               // 이미지=nanobanana / 영상=seedance
    "aspect": "1200x628",                 // type별 규격
    "duration_sec": null,                 // VID면 ~15
    "lang": "KR",
    "prompt": "<AI 생성 프롬프트 — 위닝요소+브랜드 톤 반영>",
    "negative": "<ip_safe 기반 배제 조건>",
    "reference_assets": ["<드라이브 에셋 경로/URL>"]  // 담당자 지정
  }
}
```
- **이 JSON이 툴 독립적 계약** — Higgsfield 이탈해도 재사용. `_briefAiSectionsHtml`의 이미지 프롬프트 로직을 이 구조로 확장하면 됨.
- `ip_safe` → Higgsfield negative prompt + 사람 검수 체크리스트 겸용.
- `reference_assets`는 브랜드 학습본/드라이브 컷 — 초기 담당자 수동 지정(로드맵 "초기 수동 연동 허용").

## 4. 단계적 도입 (로드맵 정합)

| 단계 | 내용 | 시점 | 상태 |
|---|---|---|---|
| 수동 | 브리프(HTML) → 담당자가 Higgsfield 웹서 수동 생성 | 파일럿(~9/14) | 무료크레딧 |
| 반자동 | 구조화 JSON export(§3) → 담당자가 페이로드로 생성 | 구독 후(10월) | ③ 구현 필요 |
| 자동 | JSON → Higgsfield MCP 호출 → 생성물 반환 → 사람 게이트 | MCP 연동 후 | ⑤ 구현 필요 |

## 5. 다음 구현 단위 (구독 전에도 가능)

1. **구조화 브리프 JSON export** — 대시보드에 `소재제작브리프(JSON)` 버튼 추가. §3 계약대로 위닝 소재 배열 출력. 생성 툴 무관·즉시 유효. **← 권장 다음 작업**
2. (구독 후) Higgsfield MCP 등록 + `gen_params` → MCP tool 매핑.
3. (MCP 후) 생성물 검수 UI(사람 게이트) — 생성 결과 미리보기 + 승인/반려 + IP세이프 체크리스트.

## 6. 리스크

- **IP 세이프티** — 생성물이 금기 위반 가능. `ip_safe` negative + **사람 게이트 필수**(자동 집행 금지).
- **비용** — 영상 $1.46/종 + 학습 $3/세션. 이터레이션 대량 시 예산 관리. 반자동 단계서 실측.
- **면책조항 엔터프라이즈 한정** — 대형 캠페인 법적 검토(구독 플랜 결정 시).
- **벤더 락인** — §3 JSON을 툴 독립 계약으로 유지해 완화.
