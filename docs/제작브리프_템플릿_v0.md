# 제작 브리프 템플릿 v0

> 위닝 소재 1건 → 이터레이션 제작 지시서로 변환하는 규격
> 최종: 2026-09-11 · 연계: [위닝요소 태그 스키마 v0](위닝요소_태그스키마_v0.md)

---

## 0. 목적·위치

위닝 크리에이티브를 **왜 먹혔는지(위닝 요소) + 무엇을 고칠지(보완) + 타이틀 고유 재료(브랜드)** 로 분해해, AI 생성 툴(Higgsfield 등)에 넣을 **제작 지시서**로 만든다. 9월 마일스톤의 "제작 브리프 가안(~9/4)"의 실체이자, #15 브리프 자동화의 출력 규격.

**슬롯이 태그 스키마 축과 1:1 매핑**된다 → 대시보드 위닝 소재에서 대부분 자동 채움 가능.

---

## 1. 슬롯 구조 + 자동화 경계

| # | 슬롯 | 소스 | 자동화 |
|---|---|---|---|
| 1 | 원본 위닝 근거 | 실적(전환·CPA·IPM·등급·Rank) | ✅ 대시보드 자동 |
| 2 | 재현할 위닝 요소 | 공통 축(hooking/USP/art_style/player_motivation) | ✅ 자동 |
| 3 | 보완 지시 | weaknesses + test_ideas + one_line_insight | ✅ 자동 |
| 4 | 브랜드 결합 | main_characters·세계관·톤·IP세이프 | ✋ 브랜드 브리프(사람) |
| 5 | 에셋 지정 | 원본 링크/파일 + 사용할 드라이브 에셋 | ◐ 반자동(담당자 확정) |
| 6 | 생성 파라미터 | 유형별 비율·길이·언어·CTA 문구 | ◐ 반자동 |

```
  · 훅          : {hooking_strategy}

  · 아트 스타일 : {art_style}

  · 약점        : {weaknesses[]}
  · 실험 방향   : {test_ideas[]}

  · 세계관/톤   : {color_tone / title_specific_theme}
  · IP 세이프   : {원본 리소스 변형 금지선 · 금칙 표현}

[5] 에셋 지정
  · 원본 에셋   : {이미지링크 | 파일명}
  · 사용 에셋   : {드라이브 폴더/컷 — 담당자 지정}

[6] 생성 파라미터
  · 비율/길이   : {BNR: 1200x628 등 | VID: 9:16·15s 등}
  · 언어        : {KR/EN/...}
  · CTA 문구    : {cta_type 기반 — 예: "지금 사전예약"}
────────────────────────────────────────
```

## 3. 실 예시 — zeus 위닝 소재 채움

원본: `P-Reward-ArtisanRewardLD-UA` (VID, 전환 11,529 — 현재 zeus 최다 전환)

```
────────────────────────────────────────
제작 브리프 — P-Reward-ArtisanRewardLD-UA
────────────────────────────────────────

[1] 원본 위닝 근거
  · 소재명/유형 : P-Reward-ArtisanRewardLD-UA / VID
  · 실적        : 전환 11,529 · 노출 13.2M · 비용 6,795만원 · 최상위 전환
  · 선정 사유   : 보상 소구 VID 중 전환 1위, 노출 대비 전환 효율 상위

[2] 재현할 위닝 요소 (유지)
  · 훅          : 압도적 보상
  · 소구점(USP) : 혜택형(무료뽑기/보상)
  · 아트 스타일 : 시네마틱 실사 합성
  · 플레이어 동기: 성취형
  · 강점        : 보상 약속 명확 · 강한 비주얼 임팩트 · 단일 주인공 스포트라이트

[3] 보완 지시 (변주)
  · 약점        : 장르/게임성 불분명 · 후킹 식상/평이 · 행동 유도 약함
  · 실험 방향   : 게임플레이 컷 추가 · 명시적 CTA 추가 · 다른 core_usp 각도 변주
  · 개선 인사이트: 보상 연출·비주얼은 강하나 장르 인지 약함 → 초반 핵심
                 게임플레이 컷 + 명시적 CTA 강화로 전환율 개선

[4] 브랜드 결합 슬롯  ※ 브랜드 브리프에서 주입
  · 등장 캐릭터 : 아티산
  · 세계관/톤   : 골드·다크 판타지 신화
  · IP 세이프   : 제우스 IP 원본 아트 변형 금지 · 신화 세계관 톤 유지

[5] 에셋 지정
  · 원본 에셋   : (zeus.json 이미지링크/파일명)
  · 사용 에셋   : 아티산 키아트 + 보상 연출 컷 — 담당자 지정(제작중 폴더)

[6] 생성 파라미터
  · 비율/길이   : VID 9:16 · 15s(원본 LD=long, 15s 컷 변주 테스트)
  · 언어        : KR
  · CTA 문구    : "보상 보증형" → 초반 게임플레이 노출 후 엔드카드 명시적 CTA
────────────────────────────────────────
```

**이터레이션 해석**: 이 소재는 "압도적 보상 훅 + 시네마틱 실사"로 전환 1위지만, 약점이 "장르 불분명·CTA 약함". → 위닝 요소(보상 훅·아트)는 **그대로 두고**, 약점만 변주(초반 게임플레이 컷 삽입 + 엔드카드 CTA)한 신규 컷을 Higgsfield로 생성 = 성공확률 높은 이터레이션.

## 4. 자동화 경계 (#15 연계)

- **[1][2][3][5원본] = 대시보드가 자동 생성** — 위닝 `key` → `window.currentCreatives`에서 소재 객체 재조회 → meta 태그·실적 조립. `js/gemini-api.js`의 위닝 인사이트 출력을 이 포맷으로 확장하면 프로토타입 완성.
- **[4] = 브랜드 브리프** — 타이틀별 1회 작성한 사람 자산에서 결합.
- **[5사용에셋][6] = 반자동** — 드라이브 에셋 지정·생성 파라미터는 담당자 확정 필요(초기 수동).

즉 **1·2·3은 지금 대시보드 데이터로 바로 채워지고**, 4는 브랜드 브리프, 5·6은 사람이 확정하는 **사람 게이트** — 회의 결론의 "완전 자동화 아닌 이터레이션 자동화 + 사람 게이트"와 정합.
