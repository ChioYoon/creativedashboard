# 브랜드 브리프 템플릿 v0

> 타이틀별 1회 작성·재사용하는 브랜드 자산 — [제작 브리프](제작브리프_템플릿_v0.md) 슬롯 4·6 공급원
> 최종: 2026-09-11 · 원천: `pipeline/game_context/{title}.md`

---

## 0. 목적·관계

**브랜드 브리프 = 타이틀의 고유 정체성(세계관·캐릭터·USP·IP 세이프)을 소재 제작 관점으로 정리한 사람 작성 자산.** 위닝 요소(공통 축, 자동 태깅)와 달리 **타이틀마다 다르고 자동화 대상이 아니다.**

두 브리프의 분업:
| | 제작 브리프 | 브랜드 브리프 |
|---|---|---|
| 소스 | 위닝 소재 meta(자동) | 타이틀 고유(사람) |
| 주기 | 소재 1건당 | 타이틀 1회(론칭 전 확정) |
| 공급 | 슬롯 1·2·3·5원본 | 슬롯 4(캐릭터·톤·IP세이프)·6(카피 톤) |

**⚠️ 중복 방지:** 파이프라인 태깅용 `pipeline/game_context/{title}.md`가 이미 세계관·캐릭터·금기를 담고 있다. 브랜드 브리프는 이를 **소재 제작 지향으로 발췌·정렬**한 것 — 원천 변경 시 game_context와 동기화. zeus는 game_context/zeus.md가 사실상 원본.

## 1. 템플릿 구조 (타이틀별 채움)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
브랜드 브리프 — {타이틀}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[A] 기본 정체성
  · 장르/포지셔닝 : {장르 + 한 줄 포지션}
  · 타겟 유저     : {코어/중위 등}
  · 세계관 한 줄  : {IP 세계관 요약}

[B] 아트 · 톤앤매너   → 제작 브리프 슬롯4 '세계관/톤'
  · 아트 스타일   : {art_style 통제어휘와 정합}
  · 컬러/톤       : {color_tone}
  · 비주얼 모티프 : {자주 등장하는 구도·오브젝트}
  · 리소스 제약   : {2D 원화 유무·3D 캡처 기반 등}

[C] 캐릭터 / IP 로스터   → 제작 브리프 슬롯4 '등장 캐릭터'
  · 주요 캐릭터   : {main_characters 후보 — 클래스/네임드}
  · 모델/셀럽/IP  : {콜라보·모델 활용 범위}

[D] USP · 카피         → 제작 브리프 슬롯6 'CTA·카피 톤'
  · 핵심 USP      : {1~3개}
  · 메인 슬로건   : {브랜드 슬로건}
  · 카피 톤       : {문체·금칙 톤}

[E] 소구 콘셉트 관행
  · 자주 쓰는 콘셉트: {검증된 소재 콘셉트}
  · 후킹 관행      : {보상 레이아웃·일정 고지 등}

[F] IP 세이프 / 금기 (Do Not)   → 제작 브리프 슬롯4 'IP 세이프'  ★필수
  · 설정 금지선   : {절대 인용 금지 설정}
  · 캐릭터/주적   : {임의 변경 금지 관계}
  · 연출 금지     : {지양할 표현·이펙트}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 2. 채운 예시 — 제우스: 오만의 신 (zeus)

> 원천: `pipeline/game_context/zeus.md`

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
브랜드 브리프 — 제우스: 오만의 신 (ZEUS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[A] 기본 정체성
  · 장르/포지셔닝 : 경쟁형 오픈필드 MMORPG (대규모 PvP/RvR) · 그리스 로마 신화 베이스
  · 타겟 유저     : 하드코어 MMORPG + 수익형('쌀먹') 유저, 중상위·중위권 집중 케어
  · 세계관 한 줄  : 부활을 꿈꾸는 티탄 12신(크로노스)에 맞서 '신의 그릇'을 증명하는 정복 서사

[B] 아트 · 톤앤매너
  · 아트 스타일   : 시네마틱 실사 합성 (언리얼 엔진 5 포토 리얼리즘) · 3D 셀셰이딩
  · 컬러/톤       : 골드·다크 판타지 (황금빛 위용 + 신화적 권위)
  · 비주얼 모티프 : 옥좌에 오만하게 내려다보는 주신 구도 · 신화급 황금 갑옷·날개 ·
                   티탄 거대 보스 · 그리스풍 오픈필드(테살리아/테베/자하브)
  · 리소스 제약   : 2D 원화 부재 → 인게임 3D 모델링 캡처·컷씬 중심

[C] 캐릭터 / IP 로스터
  · 주요 캐릭터   : 제우스(주신) / 워리어(버서커·나이트) / 로그(어쌔신·레인저) /
                   메이지(엘리멘탈리스트·오라클) / 파라곤(아티산·블레스드)
  · 모델/셀럽     : 국내 TOP급 연예인 메인 모델 — 인게임 NPC·스토리 핵심 인물로 녹임

[D] USP · 카피
  · 핵심 USP      : ① UE5 압도적 비주얼 스케일 ② 경제 특화 아티산 클래스('쌀먹')
                   ③ 중위권 배려 상생형 경쟁(수준별 RvR)
  · 메인 슬로건   : "모두에게 허락된, 가장 거대한 신화" / "신의 오만을 심판하라" / "이제, 오만해질 시간"
  · 카피 톤       : 강렬·정복 지향, 세계관 선긋기. 심층 설정 노출 지양

[E] 소구 콘셉트 관행
  · 자주 쓰는 콘셉트: 신들의 잔혹 동화(권위주의 신 + 중앙 여주인공 대항 구도) ·
                    성장 보상 각인("30만원 상당 폭풍 성장 혜택") · 일정 선점 고지
  · 후킹 관행      : 좌우 캐릭터 + 중앙 리워드 레이아웃 · 사전예약/다운로드 일자 대형 텍스트

[F] IP 세이프 / 금기 (Do Not)  ★필수
  · 설정 금지선   : 과거 '외계 문명/테라포밍' 설정 인용 절대 금지(전면 삭제됨).
                   하이테크 문명 = 프로메테우스의 불로 인간이 독자 발전(외계 아님)
  · 캐릭터/주적   : 주적은 티탄 12신(크로노스)+하수인(그림자 결사단·고르곤 부대)로 한정.
                   '하데스'를 임의 주적으로 묘사 금지
  · 연출 금지     : 복잡한 내러티브 노출 지양 · 정보 과잉/고채도 스킬 이펙트 남발 금지
                   (표정·비율·원경 스케일로 세련된 권위 전달)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 3. 운영 규칙

1. **타이틀 1회 작성, 론칭 전 확정** — 신작 준비 시 브랜드 브리프부터. game_context/{title}.md가 있으면 그것을 소스로 발췌.
2. **제작 브리프와 결합** — 자동 생성된 제작 브리프의 슬롯 4·6 플레이스홀더를 이 문서 [C][B][F][D]로 채워 최종 제작 지시 완성.
3. **IP 세이프[F]는 필수** — 게임업 IP 세이프티 리스크의 1차 방어선. AI 생성 시 이 금기를 프롬프트에 항상 포함.
4. **game_context와 동기화** — 세계관·주적·금기 변경 시 양쪽 갱신(현재 zeus는 game_context가 원본).

## 4. 다음 단계 연계

- **제작 브리프 자동화(#15)**: 슬롯 4·6이 지금은 플레이스홀더 → 브랜드 브리프의 [C][B][D][F]를 타이틀별로 주입하면 완전한 제작 지시서 완성.
- **AI 생성(Higgsfield)**: [브랜드 브리프] + [제작 브리프] + [드라이브 에셋] → 소재 자동 생성. [F] 금기는 negative prompt/가드로.
