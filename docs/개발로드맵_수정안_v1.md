## 0. 왜 수정하나 (조정 3건)

앞선 로드맵 검토에서 나온 3가지 + 그사이 실제 구축된 진척을 반영.

| # | 조정 | 이유 |
|---|---|---|
| ① | **생성툴 "1차확정 vs 정식구독" 2단계 분리** | 시트상 `툴 확정 9/30`과 `수동 파일럿 8/20 시작`이 앞뒤 모순. 실제는 Higgsfield 1차확정(무료크레딧)으로 파일럿 먼저 → 근거 쌓고 9/30 구독 결정 |
| ② | **브리프 자동화(#15) 날짜·담당 확정** | 최우선 산출물인데 시트 일정 공란이었음 |
| ③ | **A/B 성과 게이트 P1→P0 승격 · 파일럿 직후 배치** | "배너10종 중 3종 무수정"은 제작 품질 게이트일 뿐 → 성과(CTR·CPI) 증명은 A/B로만. 품질만 통과 후 구독하면 "예쁜데 안 팔리는 소재" 위험 |

**추가 반영:** 태그 고도화·브리프 규격·브랜드 브리프가 브리프 자동화의 선행/구성요소라 로드맵에 명시(시트엔 태그 고도화·브랜드 브리프 항목 부재).

## 2. 수정 플로우

```
[조사✅] → [설계: 태그고도화✅ · 브리프규격✅ · 브랜드브리프✅]
   → 생성툴 1차확정(무료)🔵 → 수동/소형 파일럿🔵
   → 품질 게이트(3/10 무수정) + A/B 성과 게이트(CTR·CPI) [둘 다 통과해야]
   → 생성툴 정식 구독 결정(9/30) → 생성 연동(수동→API/MCP)
   → 운영 도입/확장(CLoop 정착)
```
기존 대비: **툴 확정을 2단계로**, **A/B를 구독 결정 전 필수 게이트로**, **브리프 자동화 선행(태그·브랜드 브리프)을 명시**.

- **미착수 큰 건**: Higgsfield 생성 연동(브리프→소재 자동 생성, MCP), 운영 CLoop 정착.
