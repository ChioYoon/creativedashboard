1.5 데이터 연동 & 매칭 2026-06 신규
타이틀 선택 → 자동 데이터 로드

담당 타이틀(제우스: 오만의 신·도원암귀·펩 히어로즈·갓앤데몬 등)이 시스템에 등록되어, 소재 분석 화면 상단 타이틀 선택 드롭다운에서 고르면 매일 밤 자동 파이프라인이 산출한 분석 데이터(소재 태그 + 실제 KPI)가 즉시 로드됩니다. CSV 수동 업로드도 그대로 가능합니다.

· 아직 태깅 전인 타이틀을 선택하면 "아직 데이터 없음" 안내가 표시됩니다(오류 아님 — 소재 태깅 완료 후 자동 표시).
데이터 신선도 배지 v5.6 — 타이틀 로드 시 데이터 기준일과 파이프라인 생성 시각이 배지로 표시됩니다. 최신 데이터가 오래됐거나(예: "오래된 데이터 · 357일 경과") 집행 데이터가 없으면 즉시 눈에 띄어, 낡은 데이터로 잘못 판단하는 것을 방지합니다. (소재 분석·라이브 대시보드·군집화 컬럼 설정 공통)
MMP 지표 연동 (AppsFlyer / Airbridge)

Google Ads(광고비·노출·클릭)에 더해, 타이틀별로 연동된 MMP(AppsFlyer 또는 Airbridge)의 설치·전환 지표를 결합해 표시합니다. 광고 매체 데이터와 MMP 데이터를 소재 단위로 조인합니다.

레이어 우선 분석 v5.8 — 분석 순서는 ① 타이틀 선택 → ② 분석 레이어 선택(사이드바 타이틀 아래 Google Ads/MMP 토글) → ③ 필터·분석 실행입니다. 레이어를 고르면 데이터 단위가 확정되어 캠페인 필터에는 그 레이어의 캠페인만 표시되고, 저노출·저전환 제외도 그 레이어 매체 평균 하나로만 판정합니다(캠페인을 일부만 선택해도 분석 모수가 흔들리지 않음). 레이어 토글을 바꾸면 자동으로 전체 재분석되어 Google Ads↔MMP를 번갈아 비교할 수 있고, 반대 레이어 점수는 참고 컬럼으로 유지됩니다.
MMP 기준 레이어 v5.7 — 분석 기준을 MMP 기준으로 전환하면 모든 지표가 非Google 매체(MMP) 데이터로 바뀝니다. 전환 = 캠페인 유형별 합산(NU-Pre 캠페인=사전예약 등록수 · NU 캠페인=D1 잔존수)이며, CPA=비용÷전환, IPM=전환÷노출×1,000, D7 ROAS(D0~D7 누적매출÷비용)·D7 매출로 표시됩니다. 총점·등급은 MMP 품질점수(전환·CPA·IPM·D7 ROAS 4축 순위), 성과 백분위도 MMP 기준으로 재산출되고, Google Ads 총점·등급은 별도 컬럼에 유지됩니다. 소재 분석·군집화 분석·파이프라인이 모두 동일 기준입니다. 각 헤더의 ? 툴팁에서 산식을 확인하세요.
소재명 별칭 매핑 + 미매칭 리포트

광고 매체의 소재명과 GDrive 파일명이 다를 때, 소재 분석 화면 상단 미매칭 패널(기본 접힘 — 요약줄 클릭 시 펼침)에 "집행은 됐으나 매칭되지 않은 자산"이 표시됩니다. 매핑할 소재를 고른 뒤 "매핑 반영 파일 생성"을 누르면, 기존 설정을 보존한 완전한 titles_overrides.json 전체가 생성됩니다(클립보드 복사 또는 "파일 다운로드"). 이 내용을 시스템 담당자에게 전달해 반영하면 다음 야간 실행부터 자동으로 조인됩니다.

집행 링크 + 링크별 매핑 v5.7 — 미매칭 패널의 링크 컬럼에서 실제 집행 영상(YouTube)/이미지 원본을 바로 열어 확인할 수 있습니다. 링크가 2개 이상이면 같은 이름으로 서로 다른 소재가 집행된 것으로, 링크별 드롭다운으로 각 영상을 서로 다른 소재에 개별 매핑할 수 있습니다(링크별 지정이 '전체(합산)'보다 우선). 같은 소재의 버전 차이라면 전체(합산) 하나만 선택하면 KPI가 합산됩니다.
· 과거에는 일부 조각(snippet)만 생성돼 수동 병합 시 기존 설정이 지워질 위험이 있었으나, 이제 전체 파일을 안전하게 생성합니다.

3.1 점수 계산 (4개 지표 가중치)

Total Score는 4개 지표를 Rank 기반으로 계산한 후 가중치를 적용하여 산출합니다.

지표기본 가중치계산 방법의미
전환수25%Rank 기반 — 전환 많을수록 높은 점수실제 성과 (설치/구매)

6. 자주 묻는 질문 (FAQ)
"컬럼을 찾을 수 없습니다" 오류가 나와요.
해결 방법 1. CSV를 엑셀로 열어 첫 번째 행(헤더) 확인
2. 컬럼명을 표준명으로 수정 (예: "Date" → "일", "Conversions" → "전환")
3. UTF-8 CSV 형식으로 저장 후 재업로드
4. "다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)"로 저장
지표가 모두 0으로 나와요.
해결 방법 1. 전환·비용·노출수 컬럼의 값이 숫자인지 확인
2. 쉼표 포함 숫자("1,234") → 숫자만("1234")으로 변경
3. "N/A", "-", 빈칸은 시스템이 자동으로 0으로 처리 (정상 동작)
ROAS 점수가 0이에요.
Revenue 컬럼이 없거나 모든 값이 0인 경우 ROAS를 자동 제외합니다. ROAS 가중치는 나머지 3개 지표에 자동 재배분됩니다. (예: 25%+25%+25%+25% → 33.3%+33.3%+33.3%+0%)
TXT 소재가 분석에서 빠졌어요.
정상입니다. TXT 유형(광고 제목/설명 텍스트)은 크리에이티브 태그 정보가 없어 분석 대상에서 자동 제외됩니다. BNR·VID만 분석됩니다.
Gemini AI 인사이트 버튼이 비활성화되어 있어요.
API 키 미설정 상태입니다. 네비게이션 상단 "AI 설정" 버튼을 클릭하여 Google AI Studio에서 발급한 API 키를 입력하세요.
AI 인사이트가 429 오류로 실패해요.
무료 API는 분당 15회 한도입니다. 1분 후 재시도하거나 유료 플랜(분당 1,000회)으로 전환하세요.
군집화 분석을 하려면 CSV에 태그 컬럼이 반드시 있어야 하나요?
네, 필수입니다. hooking, emotion, mechanic 등 태그 컬럼이 없으면 군집화가 실행되지 않습니다. CSV 생성 시 소재별 태그를 사전에 입력해두세요.
피로도 분석에서 "없음"으로 표시되는 소재가 있어요.
기준 기간에만 있거나 비교 기간에만 있는 소재는 "신규" 또는 "사라짐"으로 별도 표시됩니다. 두 기간 모두 존재하는 소재만 순위 변동이 계산됩니다.

  • 최우수 ≥ 80점 → 즉시 Scale-up
  • 우수 60~79점 → 현행 유지
  • 양호 40~59점 → 일부 최적화
  • 보통 20~39점 → 타겟 재검토

  • Warning: 0% ~ +20% → 모니터링
  • Tired: CPA > +20% → 즉시 교체
